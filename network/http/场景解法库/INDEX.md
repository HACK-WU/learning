> **怎么用**：每个场景先自己想“怎么做”，再点进场景文件看解法。**先想后看，能力才长出来**。

## 练习顺序

1. 先做场景 1 和 4：先把“浏览器允许什么”“代理能证明什么”这两个信任边界站稳。
2. 再做场景 2 和 3：分别练缓存的正确性与写操作的失败恢复。
3. 最后做场景 5 和 6：在已有正确性约束上讨论规模、协议和回退，而不是一上来就换版本。

## 评审与证据边界

- 每个场景至少给出三条成立的路线；表格只做横向索引，正文逐一解释。
- 每个解法均有独立 SVG 机制图，图中用红色标出瓶颈、失效点或额外成本。
- 配置/命令是设计示例，不代表某个具体生产环境的完整部署文件；上线前仍需在真实版本与拓扑中验证。
- 本批不写事故故事；判断依据来自 HTTP 规范、浏览器/工具官方文档和课程已有实验。
