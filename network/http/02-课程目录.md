## 🔧 命令与工具速查索引

> 按"命令/工具 → 在哪一课"倒查。每写完一课回写此索引。

### curl

| 命令/参数 | 用途 | 计划在哪一课 |
|-----------|------|--------------|
| `curl -v` | 看请求/响应全过程（含握手） | 课 2、课 15 |
| `curl --trace-ascii` / `--trace-time` | 保存可读收发 trace 与时间戳 | 课 15 |
| `curl -X POST -H "Content-Type: application/json" -d '{}'` | 发带 JSON 正文的请求 | 课 2 |
| `curl -i` / `curl -I` | 响应含头部 / 只看头部 | 课 2、课 7 |
| `curl -L` | 跟随重定向 | 课 3 |
| `curl -O` / `curl -C -` | 下载 / 断点续传（Range） | 课 7（若涉及）、课 9 |
| `curl -w` 时间变量 | 测 DNS/连接/TTFB/总耗时分布 | 课 8 |
| `curl --compressed` | 协商压缩 | 课 8 |
| `curl -x` | 走代理发请求 | 课 9 |
| `curl -u` / `-H "Authorization: Bearer …"` | 认证头 | 课 13 |
