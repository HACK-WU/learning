## 课程故事主线

- **主角**：小航——入职三个月的全栈新人，负责公司 Web 项目的接口联调
- **冲突**：联调群天天"甩锅"——接口报错说不清是谁的锅、页面加载慢不知道慢在哪、上了 HTTPS 证书报错没人会看。看得见现象，看不见报文
- **收束**：能对任意一次 HTTP 请求做"解剖"——抓包看懂报文、把问题定位到具体一层，并对缓存 / HTTPS / 协议版本 / 认证方案给出有依据的决策

## 版本与事实基线

| 项 | 基线 | 说明 |
|----|------|------|
| HTTP 规范版本 | RFC 9110（语义）/ RFC 9111（缓存）/ RFC 9112（HTTP/1.1）/ RFC 9113（HTTP/2）/ RFC 9114（HTTP/3） | ✅ 已核实：9110/9111/9112 于 2022-06 发布，9110 为 Internet Standard STD 97（核查于 2026-09，rfc-editor.org）；课 10–12 引用时复核 |
| TLS 版本 | TLS 1.3（原 RFC 8446，现由 RFC 9846，2026-07，兼容性更新）为本课基线；TLS 1.2 用 RFC 5246 作历史对照 | ✅ 已核实（核查于 2026-09，RFC Editor）；PSK-only 与 0-RTT 的前向保密边界已注明 |
| HTTP/3 支持度 | 浏览器/服务器/CDN 支持度为**当期数据** | ✅ 已核查（2026-09）：MDN 记录多数主流浏览器具备支持；客户端、服务端/CDN 与 UDP/443 路径仍须按实际协商验证，curl 官方要求 QUIC 后端 |
| 实操环境 | macOS arm64 + 系统自带 `curl` + Chrome DevTools | 硬纪律：mkcert / mitmproxy 等额外工具**安装前先征询用户授权** |
| 起源史 | HTTP 前身：1989-03-12 Tim Berners-Lee 在 CERN 提交《Information Management: A Proposal》；1990 年底四件套完成；1991-08-06 公开新闻组发帖；HTTP/0.9"一行协议"；HTTP/1.0 = RFC 1945（1996-11）；HTTP/1.1 = RFC 2068（1997-01） | ✅ 课 1 已核实（核查于 2026-09，W3C 历史档案 + MDN）；课 10 引用时复核 |
