> 所属阶段：阶段 1《先有地图》｜ 本课类型：环境准备（附加课，不计入每阶段 2–4 课配额）

> 📖 结论已按官方文档核对（核对于 2026-11 ｜ 来源：[LangGraph JS 安装页](https://docs.langchain.com/oss/javascript/langgraph/install)、[Node.js 发布计划](https://nodejs.org/en/about/previous-releases)）

## 装什么（最小集）

本课程后续要用的环境与版本：

- **Node.js 22.x**（LangGraph JS 的运行时基线；本课程按 22.22.2 实测）
- **npm 10.x**（随 Node 附带，够用）
- **TypeScript 5.9**（`tsc --noEmit` 做类型检查，不需要构建）
- **tsx 4.x**（直接跑 `.ts`，省掉编译步骤）
- **`@langchain/langgraph` 1.6.0** + **`@langchain/core` 1.3.2**（课程所有机制实验的运行时）
- **`zod` 4.x**（定义校验用）

> **不装**：数据库 / 消息队列 / 对象存储 / Docker / 云账号。
> 本课程的全部实验都在内存里跑完，一个 `npm install` 就够了。

## 为什么这次不用克隆别人的仓库

前几版教程要求你把一份生产系统仓库克隆到本地，跟着它的源码目录逐层读。那个做法有个致命前提：**你得先有那个仓库的访问权限**，而且它的内部路径一变，所有课文的锚点就失效了。

这一版换了路线：**课程自带可运行的机制实验**（`verify/` 目录）。每个知识点都配一段能跑、能改、能打断点的小代码，你不需要读到任何公司的私有实现，就能亲手验证"挂起后节点确实重跑""通道并发写确实只留一个""策略拦在中间件层而不是工具实现里"。

遇到需要说明"生产系统为什么这么设计"的地方，课文用**结构化描述 + 伪代码**讲清机制，而不是把别人的源码截图贴上来——因为你要学的是**判断力**，不是某一家的目录结构。

## 怎么装

### 主路径：三行命令

```bash
mkdir agent-lab && cd agent-lab
npm init -y
npm install @langchain/langgraph@1.6.0 @langchain/core zod
npm install -D typescript tsx @types/node
```

然后把 `package.json` 的 `"type"` 改成 `"module"`（LangGraph JS 用 ESM 分发，省掉一类 `ERR_REQUIRE_ESM`）。

### 备选：直接用课程的 verify 工程

如果你想跳过配置，可以直接把教程里的 `verify/` 目录当成起点——它已经配好 `package.json` / `tsconfig.json`，`npm install` 之后就能跑本课程全部机制实验：

```bash
cd agent-engineering/verify
npm install
npm run core     # 课 4 / 5 / 6 / 7 的机制
```

### 不需要的东西（说明一下，免得你多装）

| 常见误装 | 为什么不需要 |
|---|---|
| `@langchain/langgraph-checkpoint-postgres` | 课程的持久化实验用 `MemorySaver` 与自写的文件 saver；换成 PG 只影响"存哪儿"，不影响"挂起语义" |
| `langchain`（上层封装包） | 本课程解剖的是**编排层**（图、通道、策略、持久化），`@langchain/langgraph` 已经覆盖；引入上层包反而多一层黑盒 |
| Docker / docker-compose | 没有任何实验需要容器 |

## 常见安装坑

| 症状（报错关键字） | 原因 | 解法 |
|---|---|---|
| `ERR_REQUIRE_ESM` / `Cannot use import statement outside a module` | `package.json` 缺 `"type": "module"` | 加上，或把文件后缀改 `.mts` |
| `Cannot find module '@langchain/langgraph'` | 在错误目录执行（父目录没有 node_modules） | `pwd` 确认在装了依赖的目录里；`npm ls @langchain/langgraph` 核对 |
| `TS2307: Cannot find module ... or its corresponding type declarations` | 用了 `moduleResolution: "node"` 而非 `"NodeNext"` | `tsconfig.json` 里设 `"module": "NodeNext"` + `"moduleResolution": "NodeNext"` |
| `The inferred type of 'X' cannot be named` | 复杂泛型推断未标注返回类型 | 给导出函数标注显式返回类型（本课程代码均已标注） |
| `SyntaxError: Unexpected token 'export'` | 用 `node` 直接跑 `.ts` 文件 | 用 `npx tsx xxx.ts`，Node 22 的 `--experimental-strip-types` 不支持全部 TS 语法 |
