## 本课程的额外必查项

InfluxDB 3.x 迭代快、术语与版本敏感，评审时除常规项外必须核查：

1. **版本号与时间点**：凡出现版本号、`latest` 标签、catalog 升级等带时间语义的断言，必须有官方文档出处，并核对 [学习档案 · 事实核查记录](00-学习档案.md) 中已核条目
2. **术语一致性**：measurement / table 两个术语并存，全文须说明二者关系，不得混用而不加注
3. **概念防混淆**：凡出现「向量」二字，必须判明是 vectorized execution（向量化执行）还是向量数据库，并在语境中消歧
4. **可运行性**：Line Protocol、SQL、CLI、Python 代码须为可照抄运行的真实语法；`1` 是 float、`1i` 是 integer 这类精度陷阱必须显式标注
