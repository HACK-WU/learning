# 课 8：升级、节点发现与 4.x 迁移

> ⬜ 待填充：滚动 / 蓝绿 / 扩缩式升级、feature flags、peer discovery、Khepri 与 4.x 废弃项。

## 课程承诺

本课将把升级拆成“前置检查 → 元数据同步 → 流量切换 → 消费者排空 → 回滚/验收”，避免把版本升级简化为替换镜像标签。
