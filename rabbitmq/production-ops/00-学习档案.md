# RabbitMQ 生产运维专项 · 学习档案

> 本子教程是 RabbitMQ 主课的后续专题，不重复 AMQP 基础、确认机制和 quorum 原理；它回答的是：**这套 broker 如何安全上线、可观察、可恢复、可升级**。

## 基线与定位

| 项目 | 值 |
|------|-----|
| 主课前置 | `rabbitmq/` 主课 4 阶段 / 12 课；至少完成课 3、课 6、课 7、课 11、课 12 |
| 版本基线 | RabbitMQ 4.3.5（Docker），以 4.3 官方文档为准 |
| 实操语言 | Python + pika；管理面使用 `rabbitmqctl`、`rabbitmq-diagnostics`、HTTP API |
| 目标 | 安全可用、可维护、可恢复、可升级、能处理跨站点边界 |
| 状态 | 骨架已建立；课 1 已写待评审，其余课程待填充 |
