# 阶段 4：工程化与上线

> 章节定位：「搬到生产环境」——单文件脚本变成能上线、能维护、能排障的服务。结课综合实战项目计入本阶段收束。

## 阶段目标

1. 按官方推荐的目录结构组织一个 LangGraph 项目，写对 `langgraph.json`
2. 给图写单元与集成测试，用假模型与 cassette 消除随机性
3. 改图代码时不断掉正在跑的任务（向后兼容）
4. 选择部署方式并接入 tracing

## 学习重点

- **`langgraph.json` 是部署的契约**：图名、依赖、环境变量都在这里声明，写错直接部署失败
- **测试的重点不是"能不能跑通"**：非确定性是 agent 测试的头号敌人，本阶段给出可复现的三件套
- **向后兼容是被低估的能力**：生产上改图最容易断掉在途任务，官方专门有一页讲它
