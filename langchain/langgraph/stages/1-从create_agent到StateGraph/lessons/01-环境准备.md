# 课 1：环境准备

> 本课采用**轻量结构**（环境准备课模板），不走完整五幕、无课级入口要素与 4.2 应用实战。
> **已有环境可跳过**：若你已完成 `../langchain/` 课程并在其 `playground/` 里跑通过代码，`langgraph` 已是依赖之一（本机实测基线 **1.2.11**），只需跑一遍下方验证命令确认版本，即可直接进课 2。

## 一、最小环境集

- Python 3.11+（LangGraph v1 的要求，低于此版本装不上）
- `langgraph`（图运行时本体）
- `langchain` + 一个模型 provider 包（本课只需跑通图，模型可先用假模型，见第四节）
- 可选：`langgraph-cli[inmem]`（本地起服务 + Studio 调试，课 13 系统讲，本课装好即可）

## 二、主路径与备选装法

**主路径（uv，与 `../langchain/playground` 一致）**

```bash
uv init langgraph-playground
cd langgraph-playground
uv add langgraph "langchain[openai]"
```

**备选 1（pip + venv）**

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -U langgraph "langchain[openai]"
```

**备选 2（Docker）**：官方部署镜像用于上线调试，本地学习不必开 Docker——见课 13。

**备选 3（已有 `../langchain/playground`）**：直接在那个目录 `uv add langgraph`，复用现成的 `.env` 与依赖锁。

## 三、验证命令

```bash
python -c "import langgraph, langchain; print(langgraph.__file__)"
```

**验证图能跑**（不调真实模型，零成本）：

```python
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    n: int

def add_one(s: State) -> dict:
    return {"n": s["n"] + 1}

g = StateGraph(State)
g.add_node("add_one", add_one)
g.add_edge(START, "add_one")
g.add_edge("add_one", END)
print(g.compile().invoke({"n": 0}))
```

**验证 CLI 与 Studio**：

```bash
uv add "langgraph-cli[inmem]"
langgraph dev
```

## 四、常见安装坑

| 症状 | 原因 | 处置 |
|------|------|------|
| `ModuleNotFoundError: langgraph` | 装在全局、跑在 venv | 确认 `which python` 与安装环境一致 |
| Python 3.10 装不上 | LangGraph v1 要求 3.11+ | 升级 Python 或用 `uv python install 3.12` |
| `langgraph dev` 找不到图 | 缺 `langgraph.json` 或图名不匹配 | 见课 12，字段写全再来 |
| 一跑就报认证错 | 没有 API key | 用假模型跑图逻辑，模型接入问题回 `../langchain/` 课 2 |
