## 三、验证命令

::: code-group

```bash [Python]
python -c "import langgraph, langchain; print(langgraph.__file__)"
```

```bash [TypeScript]
npx tsc --noEmit
node -e "console.log(require('@langchain/langgraph/package.json').version)" 2>/dev/null || \
  node --input-type=module -e "import{createRequire}from'module';console.log(createRequire(import.meta.url)('@langchain/langgraph/package.json').version)"
```

:::

> **TS 侧注意**：工程若是 `"type": "module"`（本仓库即是），裸 `node -e "require(...)"` 会失败，用第二行的 ESM 写法查版本。本机实测输出 `1.5.1`。

**验证图能跑**（不调真实模型，零成本）：

::: code-group

```python [Python]
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    n: int

def add_one(s: State) -> dict:
    return {"n": s["n"] + 1}

g = StateGraph(State)
g.add_node("add_one", add_one)
g.add_edge(START, "add_one")
g.add_edge("add_one", END)
print(g.compile().invoke({"n": 0}))
```

```typescript [TypeScript]
import { StateGraph, Annotation, START, END } from "@langchain/langgraph";

const State = Annotation.Root({
  n: Annotation<number>({ reducer: (_prev, next) => next, default: () => 0 }),
});

const g = new StateGraph(State)
  .addNode("add_one", (s) => ({ n: s.n + 1 }))
  .addEdge(START, "add_one")
  .addEdge("add_one", END)
  .compile();

console.log(await g.invoke({ n: 0 }));   // { n: 1 }
```

:::

> **TS 侧注意**：`TypedDict` 对应 `Annotation.Root`，且**每个字段都要写 reducer**（这里是最简单的"取新值"）。不写 reducer 时并发写同一字段同样抛 `InvalidUpdateError`，与 Python 侧行为一致。`invoke` 一律返回 Promise，`await` 不可省。

**验证 CLI 与 Studio**：

## 四、常见安装坑

| 症状 | 原因 | 处置 |
|------|------|------|
| `ModuleNotFoundError: langgraph`（Py） | 装在全局、跑在 venv | 确认 `which python` 与安装环境一致 |
| `Cannot find module '@langchain/langgraph'`（TS） | 在工程目录外跑，或未 `npm i` | `cd` 到含 `node_modules` 的工程目录，先 `npm i` |
| Python 3.10 装不上 | LangGraph v1 要求 3.11+ | 升级 Python 或用 `uv python install 3.12` |
| `langgraph dev` 找不到图 | 缺 `langgraph.json` 或图名不匹配 | 见课 12，字段写全再来 |
| `langgraphjs: command not found`（TS） | 装的是 `@langchain/langgraph` 而非 `-cli`，或用了 `npx` 前缀组合不对 | 装 `@langchain/langgraph-cli`，用 `npx langgraphjs dev` |
| 一跑就报认证错 | 没有 API key | 用假模型跑图逻辑，模型接入问题回 `../langchain/` 课 2 |

## 五、本机环境基线（实测）

- Python 侧：langgraph **1.2.11**（来源：`../langchain/playground/uv.lock`）
- TS 侧：@langchain/langgraph **1.5.1**、Node 26（来源：`playground-ts/package.json` 与 `node -e` 实测）、CLI `@langchain/langgraph-cli` **1.5.4**（`npm view` 实测）
- LangGraph v1 为**稳定性发布**：图原语（state / node / edge）与执行模型相比 v0.2 未变，`create_react_agent` 已废弃、让位给 LangChain 的 `create_agent`（TS 侧对应 `createAgent`）
