# 大模型本质认知 · 学习档案

> 定位：LangChain 生态的**前置基础课**。不教训练大模型，只教"大模型是什么、怎么被造出来、调用时发生了什么"，目的是让 LangChain 的每个设计决策都有根。

**不拆子教程的理由**：本主题虽有"训练工程师"与"应用开发者"两种视角，但用户已明确排除训练方向（"不是为了去做底层的、高难度的工作"），主线 100% 是应用开发者视角。训练侧内容（反向传播推导、分布式训练、手搓 Transformer）**不是次角色知识，是范围外**——不进主线，也不单开子教程。

**与 `langchain/` 课程的关系**：本教程**先修于** LangChain 主干（每课显式挂回扣锚点，指向 `../langchain/` 的对应课）；也可作为**后置复盘**（已学完 LangChain 后回头补底层认知，反而更容易共鸣）。两种读法都成立，回扣锚点双向可用。

## 大纲（阶段 → 课 → 知识点 → 关键点）

**故事主线**
- **主角**：一个只会"猜下一个词"的统计机器
- **冲突**：它读完了整个互联网，却不知道你公司的政策、不会算数、还会自信地编造——而你要拿它做生产级应用
- **收束**：看清它"能做什么、不能做什么、怎么补"，于是 LangChain 的每个组件都不再是 API，而是针对某个具体缺陷的解药

```
阶段 1：模型是怎么炼成的（"它是怎么变成这样的"）
├── 课 1：环境准备（轻量结构 · 直述模式）
├── 课 2：语言模型是什么——一个巨大的"下一个词预测器"
│   ├── token 与分词（关键点：为什么模型不认字符 / BPE 直觉 / 中英文 token 差异 / 为什么数不清 strawberry 的 r）
│   ├── 自回归生成（关键点：一次只出一个 token / 输出接回输入 / 为什么生成是串行的 / 为什么流式能逐字出）
│   └── 参数是什么（关键点：训练学到的数 / 参数量≈容量 / 同架构不同参数量的差别 / 参数 ≠ 数据库）
├── 课 3：预训练——读了什么、学会什么、没学会什么
│   ├── 预训练目标 = 猜下一个词（关键点：无标注自监督 / 一个目标为何逼出能力 / 规模定律直觉）
│   ├── 涌现能力与上下文学习（关键点：什么是涌现 / in-context learning / 为什么 few-shot 有效）
│   └── 知识截止与压缩式记忆（关键点：训练数据时间截点 / 私域数据不在内 / 有损压缩会失真）
└── 课 4：后训练——从续写机到助手
    ├── 光靠预训练不够（关键点：续写 vs 回答 / 问它问题它可能继续编问题）
    ├── SFT 监督微调（关键点：示范数据 / 学会格式与语气 / 不改变知识）
    ├── RLHF 与偏好对齐（关键点：偏好排序 / 奖励模型 / 有用诚实无害 / 对齐税）
    └── 推理模型与思考预算（关键点：思维链 / 推理时算力 / 为什么贵）

阶段 2：调用时发生了什么（"为什么它这样表现"）
├── 课 5：推理与采样——为什么同一问题每次答案不同
│   ├── 输出是一个概率分布（关键点：logits / softmax / 抽样而非查表）
│   ├── temperature 与 top_p（关键点：温度压平/锐化分布 / 核采样 / 为什么 temperature=0 也不确定）
│   └── 非确定性的工程后果（关键点：测试为何要 fake model / 缓存与复现 / 批量结果不稳定）
├── 课 6：上下文窗口与注意力
│   ├── 注意力在做什么（关键点：QKV 直觉 / 每位置看所有前文 / 位置编码）
│   ├── 上下文窗口的代价（关键点：KV cache / 复杂度直觉 / 输入 vs 输出定价差异）
│   └── lost in the middle（关键点：中间信息被忽略 / 位置效应 / 对 RAG 的直接后果）
└── 课 7：模型的六条固有缺陷
    ├── 幻觉（关键点：采样 + 压缩记忆的双重来源 / 为什么"自信地编" / 检测与缓解）
    ├── 无状态与无工具（关键点：不记上次对话 / 不会算数不会查库 / 为什么需要工具与记忆）
    ├── 知识截止与无 grounding（关键点：不知今天几号 / 不知你公司政策）
    └── 缺陷清单总结表（关键点：六条缺陷 → 后果 → 谁能补）

阶段 3：怎么改与全局收束（"所以 LangChain 为什么要那样设计"）
├── 课 8：改模型的三条路
│   ├── Prompt：不换模型，换输入（关键点：最便宜 / 占上下文 / 能力上限受模型约束）
│   ├── RAG：不换参数，换知识（关键点：外挂检索 / 可更新 / 什么时候该用）
│   ├── 微调：换参数，改风格不改知识（关键点：改格式与语气 / 门槛与成本 / 不能注入知识）
│   └── 三条路选型决策表（关键点：什么信号选哪条 / 常见误用：拿微调注入知识）
└── 课 9：收束——从模型缺陷到 LangChain 组件
    ├── 缺陷 ↔ 组件映射总表
    ├── 回到开头：重看 LangChain 的设计动机
    └── 继续往哪走
```
