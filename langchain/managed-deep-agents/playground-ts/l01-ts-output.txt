实验 2  defineDeepAgent 返回的是定义，不是 agent
============================================================
  constructor                Object
  kind                       deep-agent
  Object.keys                ["kind","config"]

  三个最关键的存在性检查：
  typeof agent.invoke        undefined
  typeof agent.stream        undefined
  typeof agent.config        object

  读法：kind === "deep-agent" 说明拿到了定义；
  invoke / stream 都是 undefined，说明它不能直接被调用——
  这正是托管版与直连 deepagents 的根本差别（课 2 展开）。

实验 3  config 的键集合：省略 = 键不存在
============================================================
  config keys                ["model","name"]
  "name" in config           true
  "tools" in config          false
  "model" in config          true

  这里没有传 tools，于是 config 里连 "tools" 这个键都没有。
  JS 侧硬取得到 undefined（不像 Python 抛 KeyError），
  所以判断"有没有配"要用 'key' in obj，不能用 === undefined。
