- [ ] `.mda/build/` 里同时出现 `agent.py`、`instructions.md`、`skills/`、`memory.py`、`sandbox/`、`identity.py`、`schedules/`、`channels/` 八类

```bash
cd 实现/duty-assistant && uv run mda build

```
