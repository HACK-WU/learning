## round-01 题目

### Q1 ｜知识点：自定义工具与运行上下文（课 4）｜ 单选

`tools/ticket.py` 写好了 `@tool`，`mda build` 全程 `exit=0`，运行起来模型却说"我没有这个工具"。最可能的直接原因：

- A. 文件名不符合命名约定，平台没扫描到
- B. 入口既没 `from .tools.ticket import query_ticket`，也没放进 `define_deep_agent(tools=[...])`
- C. `tools/` 下的模块必须在 `tools/mcp.py` 里登记一次
- D. `@tool` 缺 `parse_docstring=True`，工具没被导出

**答案**：B

### Q2 ｜知识点：技能目录与渐进披露（课 4）｜ 多选

关于 `skills/`，正确的有（多选）：

- A. 目录只扫一层：`skills/parent/child/SKILL.md` 不会被发现
- B. `SKILL.md` 的 frontmatter 缺必需字段时，`mda build` 会失败退出
- C. 平时只加载 `name` 与 `description` 标签，正文被选中后才进上下文
- D. 单个 `SKILL.md` 有体积上限，超过会被跳过
- E. `name` 必须是小写连字符形式

**答案**：A, C, D, E（B 错：只警告，`exit=0`，整张技能静默跳过）

### Q3 ｜知识点：沙箱与身份（课 6）｜ 单选

同时声明 `sandbox/` 与 `permissions=[FilesystemPermission(... 禁止写 /workspace/**)]`，实测结果是：

- A. 叠加生效
- B. 沙箱生效，`permissions` 被置为 `[]`（全清）
- C. 沙箱被禁用，`permissions` 生效
- D. 构建期报错

**答案**：B

### Q4 ｜知识点：调度与线程策略（课 8）｜ 单选

要让工作日晨报累积进同一条话题，声明式 `schedules/` 应写：

- A. `define_schedule(cron="0 8 * * 1-5", new_thread=False, ...)`
- B. `define_schedule(cron="0 8 * * 1-5", thread={"mode": "persistent", "id": "<预先建好的 UUID>"}, ...)`
- C. `define_schedule(cron="0 8 * * 1-5", thread={"mode": "ephemeral"}, ...)`
- D. 不写线程字段，`cron` 默认就续接上一条话题

**答案**：B（A 报 `TypeError`，`new_thread` 只属于运行时 `runtime.schedules.create`）

### Q5 ｜知识点：定义与编译分离（课 2）｜ 单选

`from agent import agent` 之后 `agent` 是：

- A. 已编译的 LangGraph 图，可直接 `invoke`
- B. frozen 的 `DeepAgentDefinition`，`config` 是 dict，真正 agent 由运行时编译
- C. 一个普通 dict
- D. 一个工厂函数

**答案**：B

### Q6 ｜知识点：三源分离（课 7）｜ 单选

只读报表的调用方把 `configurable` 的 `role` 写成 `admin`，然后调到了写工具。判断正确的是：

- A. 走不通：`role` 是保留键会被剥掉
- B. 走不通：`context_schema` 会校验取值
- C. 走得通：平台只剥 13 个保留键，自起业务字段原样送进工具；判权限必须读 `server_info.principal`
- D. 走得通，但 `runtime.channel` 会拦下

**答案**：C
