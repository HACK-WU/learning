## 🎯 本课目标

- 装好本课程需要的最小工具集（两侧各一套）

## ⚠️ 先记住这个坑：脚手架语言由安装渠道决定

这是本课程第一个、也是最容易卡住人的实测发现：

```bash
# PyPI 包 → 只能生成 Python 项目
uvx --from managed-deepagents mda init my-agent      # 产出 agent.py

# npm 包 → 只能生成 TypeScript 项目
npx managed-deepagents init my-agent                 # 产出 agent.ts
```

官方原文说得更直白：**"A CLI installed from PyPI refuses a TypeScript project."** 也就是说：

- 你想学 TS 那条线，`uvx ... mda init` 会直接拒绝，必须走 `npx managed-deepagents init`
- 两个包版本号各自独立发布（本次核对时两侧都是 `0.9.5`，但**别假设永远对齐**）

> 💡 顺带一个实测细节：PyPI 版与 npm 版生成的项目结构不同——Python 侧是 `sandbox/__init__.py`，TS 侧是 `sandbox/index.ts`；Python 侧有 `pyproject.toml`，TS 侧有 `package.json` + `tsconfig.json`。两侧都生成 `instructions.md`、`identity.*`、`.env`、`.gitignore`。

## 装什么（最小集）

| 用途 | Python 主线 | TypeScript 平行线 | 说明 |
|---|---|---|---|
| 运行环境 | Python ≥ 3.11 | Node ≥ 18（实测 v22 通过） | Python 侧脚手架声明 `requires-python = ">=3.11"` |
| 包与 CLI 管理 | `uv`（含 `uvx`） | `npm` / `pnpm` / `bun` | `uv` 同时充当 `mda dev` 的底层解析器 |
| MDA 包 | `managed-deepagents==0.9.5` | `managed-deepagents@0.9.5` | 由 `mda init` 自动写入清单 |
| 编译期依赖 | `langgraph-cli[inmem]`（自动） | 同左（自动） | `mda dev` 会自动解析，无需手工安装 |

**不用装**：LangSmith SDK、LangGraph 本体、任何沙箱 provider SDK——这些都随 `managed-deepagents` 一并装好，或由运行时侧提供。

> 侧面说明：本课程**不要求**你一开始就有 LangSmith 账号。`mda build` 与 `mda dev` 的启动阶段在无密钥情况下可跑通（实测）；只有真实模型调用、部署、通道、调度需要账号。

## 怎么装

### 主路径：Python 侧（推荐先走这条）

```bash
# 1. 确认 uv 可用
uv --version

# 2. 生成项目（不要 cd 进已存在的空目录，init 会自己建目录）
uvx --from managed-deepagents mda init my-agent --model "openai:gpt-5.5"
cd my-agent

# 3. 装依赖
uv sync

# 4. 确认 CLI 就位
uv run mda --version
```

**实测输出**（本机）：

```
mda 0.9.5 (80a88fc 2026-10-23)
```

生成的 `agent.py` 内容极简——只有三行有效代码：

```python
from managed_deepagents import define_deep_agent

agent = define_deep_agent(
    name="my-agent",
    model="openai:gpt-5.5",
)
```

> 注意这里**没有** `system_prompt`、没有 `backend`、没有 `checkpointer`。这不是脚手架偷懒，是 MDA 的设计核心——课 2 会讲透。

### 备选 A：TypeScript 侧

```bash
npx managed-deepagents init my-agent-ts --model "openai:gpt-5.5"
cd my-agent-ts
npm install
npx mda --version
```

等价的 pnpm / bun 写法：

```bash
pnpm dlx managed-deepagents init my-agent-ts    # pnpm
bunx managed-deepagents init my-agent-ts        # bun
```

TS 侧生成的 `agent.ts`：

```typescript
import { defineDeepAgent } from "managed-deepagents";

export const agent = defineDeepAgent({
  name: "my-agent-ts",
  model: "openai:gpt-5.5",
});
```

### 备选 B：先不装，用显式版本号试

如果你只是想先看一眼 CLI 能做什么：

```bash
uvx --from managed-deepagents==0.9.5 mda --help
npx managed-deepagents@0.9.5 init --help
```

> 显式钉版本是 beta 期的稳妥做法。本课程全部结论基于 `0.9.5`；`0.10.0-dev.*` 属 npm dev 线，行为可能变，教程不跟。

## 验证：装好了吗

逐项跑，每项都要看到预期结果才算装好：

| 项 | 验证命令 | 预期 |
|---|---|---|
| ① uv 可用 | `uv --version` | `uv 0.11.x` 或更高 |
| ② MDA CLI 可用（项目目录内） | `cd my-agent && uv run mda --version` | `mda 0.9.5 (…)` |
| ③ 项目能被编译（不需任何密钥） | `uv run mda build` | 见下方"build 的预期输出" |
| ④ 编译产物真的存在 | `ls .mda/build/langgraph.json` | 文件存在，无报错 |

`mda build` 的预期输出（实测原文，路径随你的工程位置变化）：

```text
◇  Managed app compiled
│  /abs/path/to/my-agent/.mda/build
│  
◇  Run locally
│  mda dev
│  
◇  Deploy when ready
└  mda deploy
```

要点：第一行必须是 `Managed app compiled`，第二行给你编译产物目录。看到这两行就说明静态扫描通过、胶水已生成。

TS 侧对应（`npx managed-deepagents` 是脚手架入口，运行 CLI 用 `npx mda`）：

| 项 | 验证命令 | 预期 |
|---|---|---|
| ② CLI 可用 | `cd my-agent-ts && npx mda --version` | `mda 0.9.5 (…)`（与 Python 侧同格式） |
| ③ 项目能被编译 | `npx mda build` | 同上的 `Managed app compiled` 块 |
| ④ 产物存在 | `ls .mda/build/langgraph.json` | 文件存在 |

四项全绿 = 环境就绪。

## 常见安装坑

| 症状（报错关键字） | 原因 | 解法 |
|---|---|---|
| `destination ... already exists; remove it or run mda init with another name` | `mda init` 会自己建目录，且拒绝覆盖 | 别先 `mkdir my-agent`；换一个不存在的新名字，或删掉空目录重来 |
| 想要 `agent.ts`，生成出来却是 `agent.py` | 用 `uvx` 拿到的是 PyPI 版 CLI，它只生成 Python 项目 | 改用 `npx managed-deepagents init my-agent-ts` |
| `cannot find uv`（`mda dev` 启动时） | `mda dev` 靠 `uv` 解析并拉起本地 LangGraph dev server，TS 侧同样需要 | 装 `uv`：`curl -LsSf https://astral.sh/uv/install.sh \| sh` |
| `requires OPENAI_API_KEY in .../.env` 且 `Runs fail until then` | 环境装好了，缺模型密钥（服务器能起，但一发消息就失败） | 把 key 写进项目根 `.env`，`mda dev` 保存后自动热加载 |

最后那条报错的实测原文（脱敏后照贴）：

```text
▲  The agent model 'openai:gpt-5.5' requires OPENAI_API_KEY in .../.env.
   Add `OPENAI_API_KEY=...` to .../ .env, and `mda dev` reloads it on save.
   Runs fail until then.
```
