## 课程模式

课程制（3 阶段 / 9 课 / 27 知识点）。判定依据：MDA 官方文档 29 页、覆盖项目结构 + 7 类能力声明 + 通道调度 + 评估部署，远超"一篇讲透"的速览容量。

## 语言基线

| 项 | Python 主线 | TypeScript 平行线 |
|---|---|---|
| 包 | `managed-deepagents==0.9.5`（PyPI） | `managed-deepagents@0.9.5`（npm） |
| CLI | `uvx --from managed-deepagents mda` | `npx managed-deepagents` |
| 入口 | `agent.py` → `define_deep_agent(...)` | `agent.ts` → `defineDeepAgent(...)` |
| 安装 | `uv sync` | `npm install` |
| 脚手架 | `mda init`（PyPI 包只生成 Python 项目） | `npx managed-deepagents init`（npm 包只生成 TS 项目） |

> **两条独立版本线**：PyPI 与 npm 同为 0.9.5，但两者独立发布，不要互相对齐。npm 侧另有 `dev` 预发布线（实测 `0.10.0-dev.19`），教程不跟 dev 线。
> **脚手架语言由安装渠道决定**（实测）：PyPI 版 CLI 拒绝创建 TypeScript 项目，npm 版只生成 TS 项目。这是双语教程第一个必须讲清的坑。

## 实测环境（本教程结论的事实来源）

- 环境：Linux / Python 3.12.3 / Node v22.22.2 / npm 10.9.7 / uv 0.11.6
- `mda --version` → `mda 0.9.5 (80a88fc 2026-10-23)`
- `mda init`（Python）产物：`agent.py` / `instructions.md` / `pyproject.toml` / `identity.py` / `sandbox/__init__.py` / `.env` / `.gitignore` / `README.md`
- `mda init`（TS）产物：`agent.ts` / `instructions.md` / `package.json` / `tsconfig.json` / `identity.ts` / `sandbox/index.ts` / `.env` / `.gitignore` / `README.md`
- `mda build` 两侧均可在**无 LangSmith 凭据**下编译成功，产物落 `.mda/build/`
- `mda dev` 可启动本地 LangGraph dev server；但模型调用需 `OPENAI_API_KEY`，缺失时 CLI 明确告警 `Runs fail until then`
- 无 LangSmith 账号 → `mda deploy` / `mda dev` 的真实模型调用 / 通道 / 调度 / 记忆落盘均**不可实测**，课文中一律标 `⚠️ 未实测`
