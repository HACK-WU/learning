# LangChain 课程 · 评审维度清单（SSOT）

> 本文件是「00-评审清单.md」与「00-学习档案.md」中引用的维度清单唯一事实源（SSOT）。
> 用途：每批内容（每课/收尾产物）交付前，按本清单逐项评审，P0 清零后方可勾选交付。
> 状态说明（2026-09-15）：本文件为**重建版**——原引用先于文件存在（评审清单/学习档案自建立之初即引用本文件名），本版依据课 1-6 的实际评审口径整理成文；如与既定预期不符，指出后即修订。

## 一、pedagogy 维度（教学法视角）

| # | 维度 | 检查点 |
|---|------|--------|
| PG1 | 结构完整性 | 五幕结构齐备（场景引入 → 认知冲突 → 层层揭示 → 实操验证 → 体系收束）；每个知识点六要素齐备（一句话定义 / 直觉建立 / 核心原理 / 示例演示 / 常见误区 / 一句话记住）；幕与幕之间有承接语 |
| PG2 | 目标对齐 | 讲义覆盖本课全部知识点（对照学习档案知识点表）；「本课目标」与内容一致；不超纲、不漏项 |
| PG3 | 认知负荷 | 概念渐进引入（先直觉后机制）；单段信息量可控；无未解释的跳跃；复杂内容有分步导航（本课地图等） |
| PG4 | 直觉建立 | 类比贴切且标注「类比的边界」；抽象机制有具体落点 |
| PG5 | 示证充分 | 核心结论均有示例或实测支撑；凡「实测」声称必须有真实运行证据；数值如实（含浮动范围声明） |
| PG6 | 术语纪律 | 新术语先解释后使用（零术语原则）；每知识点含行话对照表；跨课术语与前置课保持一致 |
| PG7 | 练习闭环 | 小测覆盖本课重点；答案与解析完整、正确；难度匹配学习者水平 |
| PG8 | 时效纪律 | 版本号与 API 用法以实机版本为准；与过时说法对照；未实测部分显式标注（禁凭记忆下结论） |

## 二、learner 维度（学习者视角，L1-L8）

> 核心判据：假设读者是零上下文学习者——只拿到本课讲义（配合学习档案），能否读懂、照做、自测。

| # | 维度 | 检查点 |
|---|------|--------|
| L1 | 可读懂 | 无未定义专有名词与指代；新概念先解释后使用；主线不依赖回翻前置课（跨课内容有回指说明） |
| L2 | 可照做 | 命令/代码可原样复制执行：路径真实、依赖已交代、前置步骤完整；禁「（同上）」类省略；脚本落盘位置明确 |
| L3 | 可核验 | 输出示例、数值、报错文本与真实运行一致；读者可自行复现验证；浮动数据如实声明 |
| L4 | 边界声明 | 版本/环境/模型差异显式标注；类比边界、适用范围、未实测项均有说明 |
| L5 | 导航可达 | 内部链接（上下课导航、返回目录、图表引用、官方文档）全部可达；无断链、无层级错误 |
| L6 | 自测有效 | 小测题目能检验本课核心；答案正确；解析说明「为什么」 |
| L7 | 卫生安全 | 无敏感信息（密钥/凭据/内网地址）；课程目录零产渣（临时产物放 temp 或 playground）；无危险操作误导 |
| L8 | 闭环与接力 | 学完能达成「学完应能」；含接力提示词与下一步指引；四处档案已回写（学习档案 / 评审清单 / 阶段 overview / 两份索引） |

## 三、收尾产物专项维度（占位，待收尾阶段展开）

> 以下专项维度组在「结课实战项目」与「收尾四件套」评审时叠用；具体条目于收尾阶段启动时在本文件补齐。

- **专项维度 A（A1-A6）**：结课实战项目评审叠用 + 复杂度四门槛核查。
- **专项维度 B（B1-B8）**：实战经验 / 排障速查手册 / 场景解法库评审叠用。
- **专项维度 C（C1-C11）**：场景解法库专项叠用（多解法 / 真权衡递进 / 先想后看 / 知识点挂钩 / 不适用边界 / 可溯源 / 场景质量 / 代码落地 / 效果对比 / 替代路线 / 成册形态）。

## 四、使用与分级

1. 每批交付前：对照「pedagogy 维度」与「learner 维度」逐项核查本批产物（讲义、脚本、SVG、档案回写、索引同步）。
2. 问题分级：**P0**（阻断，必须修复后才能交付）/ **P1**（应修复，交付前处理）/ **P2**（可选优化）。
3. 评审结论（含问题级别与处置）写入 `00-学习档案.md` 评审记录表 + `00-评审清单.md` 记录表。
4. P0 清零后方可勾选交付；勾选前确认课首「📖 文档核对」留痕存在。
5. 评审方式：优先独立子 agent（course-reviewer）；未创建时主 agent 内联执行并在记录中标注「独立性受限」。
