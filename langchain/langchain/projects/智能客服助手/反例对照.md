# 反例对照 · 智能客服助手

> 不是"错误示例"，而是**看起来能跑、甚至初看更简洁**的版本——只有这样才能讲清"为什么工程实践是必要的"。
> 以下反例在功能上"能回答、能退款"，正是它危险的地方。

## ❌ 反例：单文件 `naive_bot.py`（政策硬编码 + 退款直通）

```python
# naive_bot.py —— 一个文件就能跑的客服机器人（约 35 行）
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.tools import tool

# 政策直接写进提示词（初看很省事）
POLICY = """退换货：7 天无理由，质量问题 15 天内退换，运费视情况；
配送：48 小时发货，3-5 天送达；会员：V3 免运费，V4 全场包邮。"""

@tool
def refund(order_id: str, amount: float) -> str:
    """给指定订单退款。"""
    return f"订单 {order_id} 已退款 {amount} 元"   # 直接执行，无校验、无审批

model = init_chat_model("qwen3.8-flash", model_provider="openai",
                        base_url="<YOUR_ENDPOINT>", api_key="<YOUR_API_KEY>")
agent = create_agent(
    model,
    tools=[refund],
    system_prompt=f"你是电商客服，回答用户问题。可参考政策：{POLICY}。用户要求退款时调用 refund 直接办理。",
)

if __name__ == "__main__":
    while True:                                  # 无记忆：每轮是独立调用
        q = input("用户: ")
        r = agent.invoke({"messages": [{"role": "user", "content": q}]})
        print("客服:", r["messages"][-1].content)
```

> 它**能跑通**：问政策它能答（照着提示词编）、说退款它秒办。问题在下面。

## 🔍 逐条对比（5 条）

| # | 维度 | ❌ 反例 | ✅ 本项目做法 | 为什么糟 |
|---|------|---------|--------------|----------|
| 1 | 知识来源 | 政策硬编码在提示词里 | 政策放知识库，`search_policies` 检索后作答并注明来源 | 政策更新要改代码重新发布；提示词随政策膨胀；模型会**混编记忆里的旧政策**（如把 7 天说成 15 天）且无从追溯——实测中本项目场景 1 的回答带来源标注，可核对、可追责 |
| 2 | 退款安全 | `refund` 直接执行，无任何把关 | 金额分级审批（≥50 元中断人工）+ 金额一致性校验 + 每会话限额 | **钱不可逆**：模型幻觉一个金额（如把 399 说成 999）反例会照退；本项目实测模型提交 399 时先冻结等审批、金额不符直接拒绝执行 |
| 3 | 隐私保护 | 用户消息原文进模型（手机号 / 邮箱裸奔） | PII 中间件进模型前打码（`138****5678`），对话状态也只存脱敏版 | 敏感信息会进入模型服务商侧日志与本地会话记录；合规风险 + 泄漏面扩大——本项目实测手机号进状态前已被 mask |
| 4 | 对话记忆 | 每轮独立调用（无状态） | checkpointer + thread_id：第二轮记得第一轮说的订单号 | 用户要反复重复"我说的是订单 A1003"——本项目实测第二轮"它发货了吗"直接命中 A1003，无需重述 |
| 5 | 质量保障 | 无测试、无记录；改一行提示词全靠"再跑一遍看看" | 三层测试（单元 4 项 + 集成 2 项 + Evals 3 项）+ 审计中间件记录每次工具调用 | 反例改提示词后**无法知道旧场景是否退化**（如退款金额校验被顺手删掉）；本项目变更后 `uv run pytest tests/` 秒级回归，审计轨迹可回放每次工具调用 |

## 💡 一句话教训

单看"能不能回答、能不能退款"，反例和正例没有区别；差别全部藏在**失败时会怎样**——政策错了有没有来源可查、退款错了能不能拦住、隐私漏了有没有防线、改坏了有没有回归网。**能跑通 ≠ 敢交付**。
