# 阶段 3：可控性与可靠性

> 所属课程：LangChain 系统学习 ｜ 故事章节："让它靠谱：控制、上下文与安全" ｜ 上一阶段：[阶段 2](../2-Agent核心/overview.md)

## 🎯 本阶段目标

- 用中间件精确控制 agent loop（摘要、审批、重试、PII 防护）
- 掌握上下文工程三层次，学会给模型"喂对"的信息
- 实现带人工审批的高风险动作流（HITL）与内容护栏
- 搭一个最小可用的 RAG（检索增强生成）链路

## 📍 学习重点

- **中间件机制**：agent loop 的"可插入点"——理解为什么这是 LangChain 1.x 的核心扩展方式（承接课 5 的伏笔）
- **上下文工程**：上下文窗口是稀缺资源——model / tool / life-cycle 三类上下文的组织策略
- **人机协同与护栏**：高风险操作前"暂停等人点头"的中断机制；PII 检测与内容过滤
- **检索与 RAG**：给模型接上外部知识（文档 → 切分 → 向量化 → 检索 → 注入）
