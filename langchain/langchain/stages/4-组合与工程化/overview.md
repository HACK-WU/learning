# 阶段 4：组合与工程化

> 所属课程：LangChain 系统学习 ｜ 故事章节："从单兵到团队：可测、可观测、可交付" ｜ 上一阶段：[阶段 3](../3-可控性与可靠性/overview.md)

## 🎯 本阶段目标

- 掌握多智能体四大模式（subagents / handoffs / router / skills），能判断何时该拆分、选哪种模式
- 能给 agent 写测试（单元 / 集成 / evals），能接上 LangSmith tracing 排查问题
- 本阶段收束于**结课综合实战项目**（跨阶段整合，独立交付一个完整应用）

> 说明：本阶段课数（2 课）少于前三个阶段，因"多智能体"与"测试+可观测"各为一个完整主题、不宜再拆；结课实战项目计入本阶段收束，整体学习量与其他阶段均衡。

## 📍 学习重点

- **为什么需要多智能体**：单 agent 的三重极限（上下文膨胀、工具过多、职责混杂）与拆分信号
- **四大模式对比**：subagents（子代理）/ handoffs（交接）/ router（路由）/ skills（技能）的结构差异与选择依据
- **测试层次**：非确定性系统的测试策略——单元测试、集成测试、Agent Evals
- **可观测性**：tracing 是 agent 调试的主要抓手——接入、读 trace、加 metadata
