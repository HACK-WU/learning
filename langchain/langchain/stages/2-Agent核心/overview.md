# 阶段 2：Agent 核心

> 所属课程：LangChain 系统学习 ｜ 故事章节："让它动起来：工具、循环与记忆" ｜ 上一阶段：[阶段 1](../1-入门与模型层/overview.md)

## 🎯 本阶段目标

- 掌握工具、智能体、流式、记忆四个核心组件，跑通"模型 → 工具 → 循环 → 记忆"完整链路
- 能写出带自定义工具的 agent，让它自主完成多步任务（含结构化输出）
- 能做流式输出（打字机效果）并让对话具备短期/长期记忆

## 📍 学习重点

- **工具机制**：模型并不能"执行"任何东西——理解它如何请求调用、LangChain 如何回传结果，是整个 agent 能力的地基
- **agent loop**：全课程的核心引擎，理解"模型 ↔ 工具"的循环与终止条件
- **流式输出**：体验层（逐字输出）与工程层（多模式订阅）两条线
- **记忆**：模型是无状态的——短期记忆（对话内）与长期记忆（跨会话）的机制与策略
