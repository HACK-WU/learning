### 3. 语言：函数、结构体、接口

| 语法 | 一句话用途 | 在哪一课 |
|------|-----------|---------|
| `func f() (T, error)` | 多返回值（**Go 不用异常，错误当返回值**） | 课 4 |
| `defer f()` | 延迟到函数返回时执行（**LIFO，参数立即求值**） | 课 4 |
| `errors.New` / `fmt.Errorf("%w", err)` | 造错误 / **包装**错误 | 课 4 |
| `errors.Is` / `errors.As` / `errors.Unwrap` | 判等 / 取具体错误类型 / 逐层剥开（**不要用 `==` 比包装过的错误**） | 课 4 |
| `panic` / `recover` | 真正的异常（**只用于不可恢复，不是错误处理的常规手段**） | 课 4 |
| `func f(nums ...T)` | 变参（**函数体内就是切片**；传已有切片要 `f(ns...)`） | 课 4 |
| `func f() (n int, err error)` | 命名返回值（**能被 `defer` 修改**；长函数是坑） | 课 4 |
| `func (r T) M()` / `func (r *T) M()` | 值接收者 / 指针接收者（**要改原值必须用指针**） | 课 5 |
| `type T struct{ ... }` + `T{Field: v}` | 定义结构体与字面量（**推荐带字段名**） | 课 5 |
| `type T struct{ Base }` | 匿名嵌入 = **组合不是继承**（有提升、无多态） | 课 5 |
| `t.PromotedField` / `t.Base.Field` | 字段提升 / 写全路径（同名遮蔽、歧义须写全） | 课 5 |
| `` `json:"name,omitempty"` `` / `` `json:"-"` `` | struct tag：改字段名+省零值 / 完全不序列化 | 课 5 |
| `T{PromotedField: v}` | **Go 1.27+** 提升字段直接当字面量 key（**指针嵌入不行**） | 课 5 |
| `package x` / `import "模块路径/子目录"` | 声明包 / 导入（**一个目录一个包**） | 课 5 |
| `func init()` | 包初始化（**顺序不保证**，别依赖） | 课 5 |
| `internal/...` | 内部包（**编译器强制**：只有本模块能导入） | 课 5 |
| 首字母大写 / 小写 | **导出 / 不导出**（Go 没有 `public` / `private` 关键字） | 课 5 |
| `interface { M() }` | 定义接口（**隐式实现，不写 `implements`**） | 课 6 |
| `v, ok := x.(T)` / `switch v := x.(type)` | 类型断言 / type switch（**不带 ok 会 panic**） | 课 6 |
| `any` | `interface{}` 的别名（Go 1.18；**用它 = 放弃编译期类型检查**） | 课 6 |
| `var _ I = (*T)(nil)` | 编译期接口实现断言（不占变量） | 课 6 |
| `func F[T any](v T)` / `type S[T any] struct{}` | 泛型函数 / 泛型类型（Go 1.18 引入） | 课 6 |
| `comparable` / `cmp.Ordered` / `~int \| ~int64` | 约束：可比较 / 可排序 / 自定义底层类型集合 | 课 6 |
| `func (b Box[T]) Map[U any]()` | **Go 1.27** 泛型方法（**接口方法不可带类型参数**） | 课 6 |

### 4. 并发

| 语法 / API | 一句话用途 | 在哪一课 |
|-----------|-----------|---------|
| `go f()` | 启动一个 goroutine（`go` 语句立即返回，参数在 `go` 时求值） | 课 7 |
| `wg.Add(1)` / `wg.Done()` / `wg.Wait()` | 等一组 goroutine 结束；**Add 必须在 `go` 之前** | 课 7 |
| `wg.Go(f)` | **Go 1.25+ 推荐写法**，Add + go + Done 三合一（f 不能 panic） | 课 7 |
| `runtime.GOMAXPROCS(n)` | 限制**可同时执行用户级 Go 代码的 OS 线程数**（非 goroutine 数）；Go 1.25 起默认容器感知 | 课 7 |
| `runtime.NumGoroutine()` / `runtime.NumCPU()` | 当前 goroutine 数 / 逻辑核数 | 课 7 |
| `runtime.SetDefaultGOMAXPROCS()` | **Go 1.25+** 恢复容器感知的默认值与自动更新 | 课 7 |
| `pprof.Lookup("threadcreate").Count()` | **当前存活**的 OS 线程数（遍历 `allm`，非累计值） | 课 7 |
| `go test -race` / `go run -race` | 竞争检测器；**并发代码必开**，命中时退出码 66 | 课 7 |
| `make(chan T)` / `make(chan T, n)` | 无缓冲（同步交接） / 有缓冲（队列）；**容量甜点区 16~128** | 课 8 |
| `ch <- v` / `<-ch` | 发送 / 接收；**向已关闭发送 = panic，向 nil 收发 = 永久阻塞** | 课 8 |
| `close(ch)` | 关闭（＝"不再新增"，**不是清空**）；只能发送方调，重复关 / 关 nil = panic | 课 8 |
| `v, ok := <-ch` | comma-ok：`ok=false` = 已关闭且已排空，v 是零值 | 课 8 |
| `for v := range ch` | 遍历 channel；**只在 close 后退出**，否则死锁 | 课 8 |
| `len(ch)` / `cap(ch)` | 队列长度 / 容量（无缓冲恒为 0）；**不要用 `len` 判断该不该收** | 课 8 |
| `select { case ... }` | 多路复用；**多个就绪时随机选**；`default` = 非阻塞 | 课 8 |
| `time.After(d)` | 一次性超时；**循环里别用**（20 万轮 60 万次分配） | 课 8 |
| `time.NewTimer(d)` + `Reset` | **循环里超时用这个**；Go 1.23+ 未引用 Timer 可被立即 GC，channel 容量 0 | 课 8 |
| `chan<- T` / `<-chan T` | 只发 / 只收（**函数签名里写方向，是文档也是约束**；只收的不能 `close`） | 课 8 |
| `var ch chan T = nil` | nil channel 上收发**永久阻塞** → 在 select 里用来"关掉"某个分支 | 课 8 |
| `pprof.Lookup("goroutineleak")` | **Go 1.27+** 泄漏 goroutine profile；**`Count()` 恒为 0，要看 `WriteTo` 内容** | 课 8 |
| `sync.Mutex` / `mu.Lock()` + `defer mu.Unlock()` | 独占锁；**不可重入、不能复制、必须 defer 解锁** | 课 9 |
| `sync.RWMutex` / `RLock` / `RUnlock` | 读写锁；**甜点区写占 5%~25%**（快 4.9~7.6×），纯读仅 1.21× | 课 9 |
| `sync.Once` / `once.Do(f)` | 只执行一次的懒初始化（`f` panic 也算执行过） | 课 9 |
| `sync/atomic` | 单变量原子操作（只管**一个**变量）；比 Mutex 快 3~6×，分片可快 37~84× | 课 9 |
| `go test -race` / `go run -race` | 竞争检测器；命中退出码 66；**代价：慢 3.6~8.4×、内存 5.1×** | 课 9 |
| `go vet ./...` | **必须显式跑**：`copylocks` 不在 `go test` 默认 vet 子集里 | 课 9 |
| `runtime.NumGoroutine()` | 当前 goroutine 数（看**趋势**判断泄漏） | 课 9 |
| `context.WithCancel/WithTimeout` + `defer cancel()` | 取消传播；**忘调 cancel = 泄漏，274 B/个** | 课 9 / 课 10 |
| `errgroup.WithContext` | 批量任务 + 错误传播 + 取消；**零值 `Group{}` 不会取消**；`SetLimit(n)` 限并发 | 课 9 |
| `sync.Mutex` / `sync.RWMutex` | 互斥 / 读写锁（**不要复制锁**） | 课 9 |
| `sync.Once` | 只执行一次（懒初始化） | 课 9 |
| `sync/atomic` | 原子操作（计数器等简单场景） | 课 9 |
| `context.WithCancel/WithTimeout` | 取消信号与超时（**系统讲解见课 10**；课 9 只用"能收口"这一面） | 课 9 / 课 10 |
