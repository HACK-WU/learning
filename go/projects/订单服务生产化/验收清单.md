# Go 结课实战验收清单：订单服务生产化

> 运行目录：`go/projects/订单服务生产化`
> 一键复跑：`bash verify.sh`；完整输出归档在 `ALL_OUTPUT.txt`。

## 功能链路

- [x] `POST /orders` 要求 `Idempotency-Key`，金额校验失败返回 400。
- [x] 首次创建返回 202，订单先是 `pending`，worker 成功后变为 `paid`。
- [x] 支付上游失败时按配置重试，最终变为 `failed` 并保存 `last_error` / `attempts`。
- [x] 相同幂等键返回同一订单；相同 key 使用不同金额返回 409。
- [x] `GET /orders/{id}` 能查询订单；不存在返回 404。
