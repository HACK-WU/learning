## P1（会卡住学员，建议修改）

### P1-1：第一幕缺"怎么跑起来"的说明

**问题**：开头写了"实验工程：`%TEMP%/dj-lesson12-demo/idxlab`"，但**没有说怎么运行**。学员拿到路径后不知道：

- 需要先建虚拟环境吗？（课 2 建过 `dj-course`，但本课没提）
- 装 psycopg 的命令是什么？（正文 3.2 出现了，但是在"连接池"那节，索引实验其实不需要）
- `PYTHONPATH` 要怎么设？（工程用了 `apps` 子目录，不设 `PYTHONPATH` 会 import 失败）

**这是实测踩过的坑**：工程里 `shop` app 在 `apps/` 下，必须 `sys.path` 或 `PYTHONPATH` 包含 `apps` 才能导入。

**建议**：在开头"实跑环境"那一块补一个最小的运行步骤（3～5 行），区分两个环境：
- 索引/约束实验：SQLite，不需要 psycopg
- 连接池实验：需要 `pip install "psycopg[binary,pool]"`，但**不需要真的连上 PostgreSQL**（配置校验在连接前触发）

第二点尤其重要 —— 学员可能因为没有 PG 环境就跳过第三幕，而实际上那部分完全可以跑。

### P1-2：1.4 节"annotate + filter"的跳跃太大

**问题**：正文只给了两行代码：

```python
Article.objects.annotate(lo=Lower("email")).filter(lo="user5@example.com")
```

零基础学员会问：`annotate` 是干嘛的？为什么不能直接 `filter`？`lo` 这个名字从哪来的？

课 11 讲过 annotate/Subquery，但本课没有回指。

**建议**：补一句解释 —— "annotate 会往查询里加一个计算列并起个名字，filter 再对这个计算列做过滤；只有这样才能生成与索引定义完全一致的 `LOWER(email) = ?`"。并回指课 11 的表达式部分。

### P1-3：3.4 节的容量公式代入了没见过的数字

**问题**：

```
max_size ≤ (100 − 20) ÷ 8 = 10
```

`100`、`20`、`8` 三个数字里，`100`（max_connections）和 `8`（总进程数）前文有铺垫，但 **`20` 是凭空出现的**。学员不知道"预留 20"是经验值还是算出来的。

**建议**：补一句说明，例如"预留量通常给运维连接、psql、监控等留出余量，经验值是 max_connections 的 15%~25%"。

## P2（可选优化）

### P2-1：`INDEXED BY` 是 SQLite 专有语法，正文没说明

1.3 节直接用了 `INDEXED BY`，学员如果去 PG 上试会报错。建议标注"这是 SQLite 的强制索引语法，PostgreSQL 用 `SET enable_seqscan = off` 做类似验证"。

### P2-2：`dbstat` 同样需要说明

实验 12 用了 `dbstat` 查索引体积，这是 **SQLite 的虚拟表**，PG 上要用 `pg_relation_size()`。建议给一行 PG 的等价写法，方便学员在生产环境复用。

### P2-3：`~models.Q(...)` 的取反写法可以点一下

2.2 节用了 `condition=~models.Q(status="cancelled")`，`~` 号对不熟悉 Q 对象的学员不直观。建议补半句"`~` 表示取反，等价于 `NOT (status = 'cancelled')`"，并回指课 11 的 Q 对象。

### P2-4：自检第 4 题偏难

"在 Django 6.1 上，`full_clean()` 会不会校验 `CheckConstraint`？如果你看到相反的说法，可能是什么原因？" —— 第二问需要学员知道"旧文档表述过时"，这个信息讲义里有，但作为自测题略偏。可以考虑拆成两问，或改为"为什么官方文档的说法和本课的实测不一致？"
