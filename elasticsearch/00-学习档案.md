## 环境探测结论（2026-08-28）

| 探测项 | 结果 | 对课程的影响 |
|--------|------|--------------|
| Docker | **未安装**（`docker` 命令不存在） | 官方 `start-local` 脚本不可用（它依赖 Docker） |
| WSL | 已装 Ubuntu，版本 2，状态 Running | 备选路径：可在 WSL 内跑 Docker/ES，但本课程不走这条路 |
| 物理内存 | 63.4 GB | 充足，可跑多节点集群与压测 |
| 操作系统 | Windows 11 | ES 提供 **原生 windows-x86_64.zip** 发行版，自带 OpenJDK，直接 `bin\elasticsearch.bat` 启动 |

**决策**：实操主线采用 **ES 原生 zip 发行版**（版本 9.5.1，官方 Windows zip 直链已核实），不依赖 Docker。
- 首次启动会自动开启安全：生成 `elastic` 用户密码 + HTTP/TLS 证书 + Kibana enrollment token
- Windows 服务方式启动时 TLS 不自动配置，密码需用 `elasticsearch-reset-password` 生成 —— 课程统一用**命令行前台启动**以拿到完整自动配置
- Kibana 可后续按需加装（本课程核心不依赖 Kibana，实操统一用 `curl.exe` / `Invoke-RestMethod`）
