# 阶段 1 · 三个控制台的四小时

> **故事章节**：「开场」——主角（一次下单请求）登场，先让你真实感受"三个信号各自为政"的代价，再介绍 OTel 这位主角，最后亲手跑通第一条链路。

## 一、阶段目标

学完本阶段你应该能够：

1. **说清**可观测性碎片化的具体代价——不是"不方便"，而是"事故定位时间从十分钟涨到四小时"这种可量化的损失
2. **划清** OTel 的能力边界：它提供什么、不提供什么（尤其：它**不是**后端、**不是**存储、**不是**可视化）
3. **跑通**端到端：在本机用 Python 插桩出第一条 Trace，并能在后端界面上看到它

## 五、本阶段的高频困惑点（预判）

> 学习时若遇到以下问题属正常，课内会正面回应：

1. **"我有 Prometheus + ELK 了，为什么还要 OTel？"** → OTel 不替换它们，而是统一**插桩层**与**传输层**；换后端不再改代码
2. **"OTel 能存数据吗？能画图吗？"** → 都不能。它是采集与传输标准，存储与可视化归后端（Jaeger / Prometheus / Grafana / 商业 APM）
3. **"Logs 到底稳了没有？"** → ⚠️ **规范层已 Stable，但各语言 SDK 差异极大**：Java / PHP / .NET / C++ 的 Logs SDK 已 Stable，**Python 与 JS 仍是 Development，Go 是 Beta**。说"稳定"必须指明是哪一层
4. **"为什么有三个版本号？我该看哪个？"** → 规范（1.56）、Collector（0.159）、Python SDK（1.44）各自独立演进，看哪个取决于你在配谁

**本阶段已交付的核心结论**

| 课 | 核心结论 |
|---|---------|
| 课 1 ✅ | **碎片化不是"没有数据"，是"有数据但连不起来"**。一次跨服务事故 164 分钟里只有约 11 分钟在真正解决问题（有效占比约 6%）；三个信号各答一问缺一不可，割裂的技术根因是三个后端，但**可修复的切入点是关联标识 `trace_id`**。⚠️ 诚实口径：OTel 能砍掉的是"找数据"的时间，砍不掉"等人"的时间——课 12 结算收益时将区分核算 |
| 课 2 ✅ | **OTel 是采集与传输的标准，不是可观测性的全部**。四大组件（规范 / API+SDK / OTLP / Collector）让"插桩一次，随处消费"成立；五条边界（不是后端 / 不存储 / 不做可视化 / 不做告警 / 不是银弹）划清了它不做什么——**控制源头比控制终点值钱得多**。三套版本号互不相干，**成熟度必须按"信号 × 语言"逐格查**（规范层 Logs Stable ≠ Python SDK Logs Stable）。2026-05-21 CNCF 毕业，**"等它再成熟一点"这个拖延理由正式失效**。⚠️ 实测纠正：未配置 SDK 时返回的是 `ProxyTracerProvider` 而非 `NoOpTracerProvider`，**`trace_id == 0` 才是最可靠的诊断判据** |
| 课 3 ✅ | **"跑通"和"送到"是两件事**。OTel 的导出失败是**沉默**的：实测五种错误配置（gRPC→4318 / HTTP→4317 / HTTP 漏 `/v1/traces` / 死端口）下 `force_flush()` **全部返回 `True`** 且程序退出码为 0，但数据**全部静默丢弃**——**唯一可信判据是查后端 `GET /api/services`**。三条硬结论：①**跑通 ≠ 送到**；②**4317(gRPC) 与 4318(HTTP) 不可混用**，HTTP 必须带 `/v1/traces`；③**`service.name` 必须设**，否则后端统一显示 `unknown_service`，多服务挤在同一名下彻底失去分辨能力。Resource 是**进程级**的"谁发的"（快递面单），Attributes 是**每次操作**的"发生了什么"（商品标签），优先级为**代码 > 环境变量 > 默认**，`merge` 时**后者覆盖前者**。⚠️ 两处实测纠正：Jaeger 镜像名 v1→v2 已变更（`all-in-one` → `jaeger`，v1 于 2025-12-31 EOL；本机实测 v2.20.0）；`get_tracer()` 早于 `set_tracer_provider()` 时 span `trace_id=0` 被静默丢弃（承接课 2 的 `ProxyTracerProvider` 结论）。⚠️ 诚实口径：本课为教学简化让应用**直连后端**，生产环境中间应有一层 Collector——这个坑课 10 正面解决 |
