**本项目实测抓出并修复的 6 个真 bug**

1. **自检误报**：探针没进索引时 `commit` 以 rc≠0 失败，被误读成"钩子拦住了"。修：先 `git diff --cached --quiet` 证明探针已入索引。
2. **`(( x++ ))` 杀死脚本**：计数器为 0 时自增表达式结果为 0，`set -e` 终止。改前置自增。
3. **`cond && return N` 连累调用方**：AND 列表为假时整表返回 1，`set -e` 终止。改 `if ... fi`。
4. **`--force-with-lease` 语义误解**：它只保证"我上次 fetch 之后远端没再动过"，**不检查历史包含关系**；用 `HEAD:master` 推还会退化成无条件 force。
5. **bisect 三连环坑**：探针在仓库里导致 `bisect start` 被拒 / 提交内容重复导致 `HEAD~N` 越界 / `bisect run` 找到结果返回非 0 中断脚本。
6. **include guard 缺失**：5 个库都 source `core.sh`，重复加载触发 `readonly` 冲突并重置临时目录数组。

**两处认知被实测修正**

- `--cached` 的触发条件比讲义原述更精确：只有「**位置参数**模式之后、且无 `--` 分隔」才 exit 128；用 `-e` 传模式或带 `--` 都是安全的。
- 演示体积必须用随机数据：1MB 零字节只增 28 KB，1MB 随机增 1048 KB，**相差 37 倍**。
