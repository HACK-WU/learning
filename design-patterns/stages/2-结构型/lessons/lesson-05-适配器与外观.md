# 课 5 · 适配器 与 外观（统一不一致的接口）

> 本课在故事主线中的情节定位：订单系统要接顺丰、京东物流、德邦三家，每家 API 的方法名、参数顺序、返回结构都不一样。你的代码里全是 `if carrier == "sf": ...` 的胶水。**这一课解决：怎么让外部五花八门的接口，对内都长成一个样。**

## 本课目标

- 掌握适配器模式：把一个接口转成另一个接口。
- 掌握外观模式：给复杂子系统提供简单统一入口。
- 能区分「适配器」和「外观」各自解决什么问题。

## 知识点清单

1. 适配器模式（对象适配 vs 类适配，Python 多用对象适配）
2. 外观模式（门面，屏蔽子系统复杂度）
3. 场景识别（何时适配、何时门面）
