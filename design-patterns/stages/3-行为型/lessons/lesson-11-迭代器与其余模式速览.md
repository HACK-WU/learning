# 课 11 · 迭代器 与 其余模式速览

> 本课在故事主线中的情节定位：订单系统有一堆「集合」要遍历——订单列表、商品清单、日志流。同时还有几种低频模式你偶尔会在别人代码里撞见。**这一课解决：Python 里迭代器已经内建，几乎不用手写；其余 5 种模式各一句话 + 何时用即可。**

## 本课目标

- 掌握迭代器模式：Python 的 `__iter__`/`__next__` 协议 + 生成器。
- 速览备忘录、中介者、访问者、享元、解释器五种模式（一句话 + 何时用）。
- 收束：形成 GoF 23 种的完整地图。

## 知识点清单

1. 迭代器模式（生成器/协议，Python 内建支持）
2. 备忘录 / 中介者 / 访问者 / 享元 / 解释器 速览
3. GoF 23 种完整地图收束
