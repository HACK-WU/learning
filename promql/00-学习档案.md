> 创建日期：2026-08-27

## 学习者画像

| 维度 | 设定 |
|------|------|
| 当前水平 | 零基础：未接触过 Prometheus，监控概念陌生 |
| 学习目标 | 动手实操：能独立写出 PromQL 查询、告警规则、Grafana 面板 |
| 输出偏好 | Markdown 文档 + 图表 + 每课带实操练习 |
| 实操环境 | demo.promlens.com 在线演练场（免安装，用户指定）；后期可切换本地 Docker |

## 课程结构

- 阶段 1：地基与数据模型（L1-L3）—— 看懂数据长什么样
- 阶段 2：核心语法（L4-L7）—— 会取向量、做运算、拼数据
- 阶段 3：函数与聚合（L8-L10）—— 掌握日常 80% 的查询套路
- 阶段 4：实战应用（L11-L12）—— 写告警规则、配 Grafana 面板
