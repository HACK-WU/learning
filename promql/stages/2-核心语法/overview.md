# 阶段 2：核心语法

> L4 - L7 | 会取向量、做运算、拼数据

## 阶段目标

学完本阶段，你能回答：

- 瞬时向量与范围向量的区别，方括号 `[5m]` 到底取了什么
- 怎么用标签匹配器从一堆序列里筛出你要的那几条
- 算术、比较、逻辑运算怎么用在查询上，`bool` 修饰符是干嘛的
- 两个不同指标怎么按标签拼在一起做除法（如内存使用率）

## 本阶段课程

| 课次 | 主题 | 状态 |
|------|------|------|
| L4 | 瞬时向量 vs 范围向量：[5m] 到底取了什么 | ✅ |
| L5 | 标签匹配器四兄弟：= != =~ !~ | ✅ |
| L6 | 运算符：算术、比较、逻辑与 bool 修饰符 | 🔄 |
| L7 | 向量匹配：on/ignoring 与 group_left 拼接 | 🔲 |

## 阶段通关标准

独立完成：给定一个业务问题（如「各机器当前内存使用率」），能自己写出「筛选 + 运算 + 拼接」的完整查询，并能说清查询里每个部分各取什么形态的数据。
