# 运维专项（Kubernetes · 子教程）

> 定位：面向**集群运维 / SRE**——把「交付一个集群、把它养稳、出事能恢复」这摊事说清。
> 前置：主线**阶段 6（排障 · 运维 · 扩展）**及之前的基础知识；子教程**不重复主线内容**，只讲次角色视角。
> 怎么进入：① 已学主线 → 直接按下面的课清单学；② 只为运维而来 → 先补主线阶段 1-4，或按各课课首的「前置提示」按需回看主线课。

## 故事主线

- **主角**：一个刚接手、还没人值班的集群
- **冲突**：应用跑起来了，但没人回答"磁盘满了谁管""证书哪天过期""控制面挂了怎么救""这个月账单为什么翻倍"
- **收束**：学完后能回答"**养一个生产集群到底要做哪几件事，以及哪些事不做一定会出事**"

## 学习路径

```text
课 1 交付 → 课 2 节点 → 课 3 etcd/控制面 → 课 4 升级与证书
        └→ 课 5 可观测 → 课 6 治理与成本 → 课 7 备份与变更
```

依赖顺序：课 1 是总入口（先有一个"可交付"的完整图景）；课 2-4 是**保命线**（节点 / 数据 / 证书，这三项出事都是集群级故障），建议顺序学；课 5-7 是**体系线**（看得见、管得住、救得回），可按需跳课，但课 7 依赖课 3 的备份基础。

## 边界声明

- **不重复主线**：同一知识点"应用怎么用"在主线讲、"运维怎么养"在本教程讲（见上表）。
- **不做 Phase 3 / Phase 5**：本子教程不收口综合项目、不产领域三产物（那是全课程收尾，主线已完成）。
- **不配课级应用实战 / 源码解析**：按子教程轻量口径，`应用实战/`、`源码解析/` 只收主线课。
- **实操边界**：kubeadm 多机搭建、跨版本升级、真实 HA 故障演练**无法在 kind 上真跑**（kind 节点是容器、无真实 systemd 与多机网络），相关知识点将**显式标注为原理课并给出生产对照**；etcd 备份恢复、驱逐阈值、证书检查、监控栈安装、多租户配额与网络策略等**可在本机 kind 集群上真实操**（课文件生成前逐课确认环境改动并征得用户同意）。
- **CNI 补充说明**（课 6 实测更正）：本机 kind 集群 `k8s-c1-calico` 装的是 **Calico**（`kubectl get installation -o jsonpath='{.items[0].spec.cni.type}'` → `Calico`），**NetworkPolicy 可真跑真验证**；kind 默认的 **kindnetd 不支持** NetworkPolicy（策略能建但不生效）。涉及网络策略的实操前务必先确认 CNI 类型。

## 📌 跨课实测要点（供后续课程复用）

- **etcd 工具在 etcd Pod 内**，不在控制面容器（`docker exec` 报 `etcdctl: not found`）—— 课 3、课 7 均验证。
- **`kubectl get -o json` 默认不返回 managedFields**，需 `--show-managed-fields`（课 7 实测 0 条 vs 3 条）。
- **策略/配置变更后需数秒才生效**（VAP 改 Warn 实测需 sleep 5），立即验证会看到旧行为。
- **删除命名空间要同步等待**（默认 `delete` 即同步），`--wait=false` 会导致后续对比实验无效。
- **统计命令别把错误行计入**：`kubectl get ns X 2>&1 | wc -l` 会把 `NotFound` 算作 1，误报残留。
