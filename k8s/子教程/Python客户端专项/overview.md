# Python 客户端专项（Kubernetes · 子教程）

> 定位：面向**要用代码操作集群的人**——把「用 Python 调 Kubernetes API」这件事从装库讲到能写出可在生产跑的控制器。
> 前置：主线**阶段 1~2**（Pod / Deployment / 声明式 API）与课 15（RBAC）；子教程**不重复主线内容**，只讲「同一件事用代码怎么做」。
> 怎么进入：① 已学主线 → 直接按下面课清单学；② 只为写代码而来 → 先补主线课 2（声明式 API）、课 3（Pod）、课 5（Deployment）、课 15（RBAC），或按各课课首「前置提示」按需回看。

## 与主线的关系

主线走的是**kubectl / YAML 视角**（写清单、apply、 describe 排障）；本教程走的是**代码视角**（同一批操作用 Python 怎么做、坑在哪、怎么写得不像脚本而像一个能长期跑的程序）。

## 故事主线

- **主角**：一个只会 `kubectl apply` 的人，被要求"把这个流程自动化"
- **冲突**：照着 README 抄能跑通，但一到"改一个字段""等它就绪""出错重试""在 Pod 里跑"就全崩——**因为 kubectl 替你做的那些事，代码里没人替你做**
- **收束**：学完后能回答"**用代码管集群，哪些事 kubectl 白送、哪些事必须自己写，以及怎么写才不会半夜挂**"
