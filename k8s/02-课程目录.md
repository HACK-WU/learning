## 阶段 4：配置 · 存储 · 资源 · 工程化

> 阶段概览：[配置 · 存储 · 资源 · 工程化](stages/4-配置存储资源工程化/overview.md)

### 课 11：ConfigMap 与 Secret（✅ 已完成 · 2026-09-11）

> 讲义：[lesson-11-ConfigMap与Secret.md](stages/4-配置存储资源工程化/lessons/lesson-11-ConfigMap与Secret.md)

- ConfigMap — 环境变量永不更新 / 卷挂载 50~100 秒后更新
- Secret — base64 非加密；默认 0644 需 `defaultMode: 0400`；走 tmpfs 不落盘
- 投射卷 projected volume — ConfigMap + Secret + downward API 合并挂载
- 配置变更与滚动更新联动 — 不自动触发，`rollout restart` 或 checksum 注解

### 课 12：存储：Volume / PV / PVC / StorageClass（✅ 已完成 · 2026-09-11）

> 讲义：[lesson-12-Volume与PVPVC.md](stages/4-配置存储资源工程化/lessons/lesson-12-Volume与PVPVC.md)

- Volume 基础 — 根文件系统活不过容器重启；emptyDir 活过重启但活不过 Pod 删除（标记法实测）
- PV / PVC / StorageClass — 两层抽象；一对一绑定、容量向上取；`WaitForFirstConsumer` 延迟绑定
- 有状态应用落地 — 回收策略（默认 `Delete` 删 PVC 即删数据）；PVC 删除保护

### 课 13：资源 · 调度 · 扩缩容（✅ 已完成 · 2026-09-11）

> 讲义：[lesson-13-资源调度扩缩容.md](stages/4-配置存储资源工程化/lessons/lesson-13-资源调度扩缩容.md)

- requests 与 limits — requests 管调度、limits 管运行时；**只写 limits 会自动补齐 requests（实测）**
- QoS 与驱逐顺序 — 三档判定（实测）；⚠️ **官方文档：kubelet 不用 QoS 决定驱逐顺序**，QoS 仅可估计
- 调度、亲和性与污点容忍 — Pending 原文 `1 node(s) had untolerated taint`；资格问题 vs 容量问题
- HPA / VPA / Cluster Autoscaler — **HPA 实测 1→5→9 副本**；扩得快缩得慢（300s 稳定窗口）
- ResourceQuota 与 LimitRange — 超额是「拒绝创建」非 Pending；设 quota 后 Pod 须写全资源声明
- PriorityClass 优先级 — **QoS 是舱位、PriorityClass 是身份**；不写默认 **0**（实测）；**抢占≠驱逐**（调度阶段 vs 运行阶段）；`value` 建后不可改

### 课 14：Helm · Kustomize · 可观测性（✅ 已完成 · 2026-09-11 · 阶段收官）

> 讲义：[lesson-14-Helm与Kustomize与可观测性.md](stages/4-配置存储资源工程化/lessons/lesson-14-Helm与Kustomize与可观测性.md)

- Helm 与 Chart — 模板 + 版本台账；**release 是 Secret 且未加密**；回滚=新增 REVISION
- Kustomize — 底稿 + 补丁，**无模板逻辑、无状态**；`configMapGenerator` 哈希变则名字变
- 可观测性（metrics-server 与日志架构） — 三支柱各带一半；日志在 `/var/log/pods/...`，会轮转会消失

## 阶段 5：安全体系

> 阶段概览：[安全体系](stages/5-安全体系/overview.md)

### 课 15：认证 · 授权 · 准入：RBAC 与 ServiceAccount（✅ 已完成 · 2026-09-11）

> 讲义：[lesson-15-RBAC与ServiceAccount.md](stages/5-安全体系/lessons/lesson-15-RBAC与ServiceAccount.md)

- 云原生安全 4C 模型 — RBAC 属 Cluster 层、PSA 属 Container 层
- API 安全三段式 — 认证/授权/准入；**坏 token 401 vs 无 token 403（system:anonymous）**
- RBAC — 默认拒绝、只加不减；Role 与 ClusterRole 区别在**作用域**
- ServiceAccount 与 token 安全 — 绑 Pod（删 Pod 即失效）；**默认挂载是最易忽略的提权风险**

### 课 16：Pod 安全：PSA 与 securityContext（✅ 已完成 · 2026-09-11）

> 讲义：[lesson-16-Pod安全PSA与securityContext.md](stages/5-安全体系/lessons/lesson-16-Pod安全PSA与securityContext.md)

- Pod 安全标准 PSA — 三档累积；**baseline 挡"碰宿主机"，restricted 是"全或无"**
- securityContext 与 capabilities — **默认 root + 14 项能力**；四件套（非 root / 禁提权 / 丢能力 / seccomp）
- 镜像与供应链安全 — 固定 digest、最小化基础镜像、持续扫描、签名（**Code 层**）

> 🧪 **配套应用实战**：[16 · 合规检查把应用卡住了](应用实战/16-合规检查把应用卡住了.md) — 打完基线标签应用「起不来」却零报错，真相要往下追一层

### 课 17：Secret 加固 · etcd 加密 · 审计（✅ 已完成 · 2026-09-11）

> 讲义：[lesson-17-Secret加固与etcd加密与审计.md](stages/5-安全体系/lessons/lesson-17-Secret加固与etcd加密与审计.md)

- Secret 加固与 etcd 静态加密 — **base64 不是加密**；`identity` 必须最后；KMS v2 生产推荐
- 审计日志 — **默认关闭**；四级别四阶段；Secret 别用 `RequestResponse`
- 运行时安全与威胁模型 — **五条泄露路径**；k8s 只在 API 层默认收紧
