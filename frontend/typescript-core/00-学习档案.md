## ⚠️ 版本事实基线（核查于 2026-08，来源：TypeScript 官方博客）

本课程的工程化部分必须按 **TypeScript 7.0** 讲，市面上大量教程仍停留在 5.x，配置方式已过时：

| 事实 | 内容 |
|------|------|
| TS 7.0 发布 | 2026-07-08 正式发布（Go 原生移植，代号 Project Corsa），官方称全量构建提速 8–12x |
| TS 6.0 发布 | 2026-03-23，最后一个基于 JS 代码库的大版本，为 7.0 铺路 |
| 安装方式 | `npm i -D typescript` 即得 TS 7 的 `tsc`（`latest` = 7.0.2） |
| TS 7 无 API | 7.0 **不提供编程 API**（7.1 才有新 API）；typescript-eslint 等工具需通过 `@typescript/typescript6` 并存 |
| 新默认值 | `strict: true`、`module: esnext`、`noUncheckedSideEffectImports: true`、`libReplacement: false`、`stableTypeOrdering: true`（不可关）、`rootDir: ./`、`types: []` |
| 变硬错误 | `target: es5`、`downlevelIteration`、`moduleResolution: node/node10/classic`、`module: amd/umd/systemjs/none`、`baseUrl`、`esModuleInterop/allowSyntheticDefaultImports: false`、`alwaysStrict: false` 等 |
| 新 CLI 参数 | `--checkers N`（类型检查并行度，默认 4）、`--builders N`、`--singleThreaded` |
| 生态限制 | Vue / MDX / Astro / Svelte / Angular 模板等依赖 TS API 的工作流暂只能用 TS 6 |

> 详细拆解见阶段 4 课 10 知识点 10.1。课 1 给出的最小 tsconfig 即为 TS 7 可用版本，避免学员先学一套过时的。

## 🚧 前置知识约定（重要）

TS 建立在 JS 之上，本课程**假设你已具备 ES6 基础**：函数与箭头函数、解构与展开、模板字符串、class 语法、`Promise` 与 `async/await`、`import/export` 模块语法。

你的 JS 课程 [`javascript-core`](../javascript-core/02-课程目录.md) 目前进度为 3/36 知识点，尚未覆盖上述全部内容。处置原则：

| 遇到未学的 JS 概念 | 怎么办 |
|-------------------|--------|
| 语法层面不影响理解 TS 概念（如示例里用了 `Promise<T>`） | 本课**一句话说明**即可继续，不阻塞 |
| 概念层面影响理解（如结构化类型涉及对象、原型） | 回指 `javascript-core` 对应课，标注「可先跳去补」 |
| 需要动手但缺 JS 基础 | 给出最小可用代码片段，抄着跑不影响理解主线 |

> 每课骨架的「前置依赖」字段会写明本课用到哪些 JS 概念，以及哪些需要回补。

**大纲评审 P1 明细（已全部在落盘产物中落实）**：

1. 【前置缺口】学员 JS 基础只完成 3/36 知识点，而 TS 课程示例依赖 ES6 函数 / 解构 / 模块 / class / Promise → 处置：本档案加「前置知识约定」章节 + `01-学习路径总览.md` 加「课程边界与前置」，每课骨架标明所需 JS 概念与回补路径。
2. 【完整性】初版大纲**漏了「类与类型」**（public/private/protected、参数属性、implements、抽象类）——零基础学员写 TS 几乎必用 → 处置：新增课 7《类与接口的类型世界》，插在「收窄」之后（依赖收窄的 `unknown` 处理先讲完），阶段 2 由 3 课扩为 4 课。
3. 【完整性】漏了「不写 .ts 也能用类型」的轻量路线（JSDoc + `checkJs`）——TS 7 正好改了 JS 支持行为 → 处置：并入课 12 知识点「运行与构建工具分工」的关键点。
4. 【教学逻辑】TS 7 的破坏性变更集中且多（`strict` 默认开、`rootDir`/`types` 默认值变了、一批旧选项变硬错误），零基础学员若照网上 5.x 老教程配置会直接撞墙 → 处置：课 10 知识点 10.1 专门讲 TS 7 新默认与迁移；**课 1 的最小 tsconfig 直接给 TS 7 可用版本**，从第一节课就建立正确的配置直觉。
