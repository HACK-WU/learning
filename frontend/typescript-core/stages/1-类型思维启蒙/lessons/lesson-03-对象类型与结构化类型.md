# 第 3 课：对象类型与结构化类型

> 所属阶段：阶段 1《类型思维启蒙》｜ 水平：零基础 TS
> 本课知识点：对象类型：interface 与 type、结构化类型系统、类型断言与 satisfies
> 故事情节：主角给一个业务对象写类型，撞见一个反直觉现象——**两个从没见过面的类型，居然能互相赋值**
> ✅ 状态：⬜ 待编写 ｜ 实操环境：Node.js v22.14.0 + TypeScript 7.0.2

## 🎯 本课目标

- 为业务对象写出类型定义，正确使用可选属性、只读属性、索引签名
- 解释结构化类型（鸭子类型）的兼容规则，预判两个类型能否互相赋值
- 说清 `as` 能做什么、不能做什么，以及 `satisfies` 解决了 `as` 的什么问题

## 📌 知识点导航

| # | 知识点 | 关键点 | 状态 |
|---|--------|--------|------|
| 1 | 对象类型：interface 与 type | 可选与只读属性 / 索引签名 / interface 与 type 的能力差异 / 声明合并 | ⬜ |
| 2 | 结构化类型系统 | 鸭子类型 / 结构化兼容规则 / 多余属性检查 / 与名义类型的对比 | ⬜ |
| 3 | 类型断言与 satisfies | `as` 能做什么不能做什么 / 非空断言 `!` 的陷阱 / `as const` / `satisfies` 的用途 | ⬜ |

## 📦 前置依赖（JS 概念）

| 用到的 JS 概念 | 掌握要求 | 回补 |
|---------------|---------|------|
| 对象字面量与属性访问 | 需理解 | 入门级，本课内可覆盖 |
| 原型与原型链 | **不要求**（结构化类型与原型无关，勿混淆） | [JS 课 6 原型与类](../javascript-core/02-课程目录.md)（未学，不影响本课） |

> ⚠️ **刻意澄清**：TS 的"结构化类型"与 JS 的"原型链"是两回事。前者是**编译期的形状比较**，后者是**运行时的属性查找**。本课只讲前者。
