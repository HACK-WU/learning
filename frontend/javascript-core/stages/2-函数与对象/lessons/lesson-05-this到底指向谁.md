# 第 5 课：this 到底指向谁

> 所属阶段：阶段 2《函数与对象》｜ 水平：入门 ｜ 本课知识点：this 的四种绑定规则、箭头函数的 this、手写 call·apply·bind 与 new
> 故事情节：主角把对象方法传给 `setTimeout`，结果 `this.name` 变成 `undefined`——"this 丢了"。这一课就是把丢掉的东西找回来
> ⏳ **状态：骨架（正文待 Phase 2 填充）**

## 🎯 本课目标

- 对任意调用点说出 `this` 的指向，并按**优先级**说明是哪条绑定规则生效
- 指出对象方法、事件回调、原型方法三处误用箭头函数的后果
- 手写一个可用的 `bind`，并说清 `new` 的四步过程

## 📌 知识点清单（含关键点）

### 知识点 1：this 的四种绑定规则

- 关键点：默认绑定（严格 / 非严格）/ 隐式绑定与**隐式丢失** / 显式绑定 `call`·`apply`·`bind` / `new` 绑定 / 四条规则的优先级排序

### 知识点 2：箭头函数的 this

- 关键点：词法 `this`，**定义时**确定 / 与四种规则无关，也无法被 `call`·`apply`·`bind` 改变 / 常见误用场景：对象方法、事件回调、原型方法

### 知识点 3：手写 call·apply·bind 与 new

- 关键点：手写 `call` / `apply` / `bind` 揭示机制（`bind` 需处理 `new` 的情况）/ `new` 的四步过程 / 绑定丢失的真实案例与修复手段
