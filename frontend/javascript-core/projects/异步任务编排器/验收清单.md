## L2 · 说清（理解为什么）

> 判定标准：**合上代码，用自己的话讲给一个没看过的人听，他能听懂。**

### 并发与事件循环

| # | 自测项 | 关键答案 |
|---|---|---|
| 7 | 为什么并发上限必须靠"主动计数"，而不能靠" JS 自己限制"？ | JS 单线程 + 事件循环只负责**调度**，它不知道哪些算"并发任务"。并发是**应用层概念**，必须自己数（课 7） |
| 8 | `finally` 在 `semaphore.run()` 里起什么作用？漏了会怎样？ | 保证名额一定归还。**漏一次，并发数永久少一**，队列后面的任务永远醒不过来（死锁）（课 11） |
| 9 | 为什么释放函数要做成幂等？ | 调用方可能重复调用；不幂等会把计数搞乱，多放任务进来（课 3 闭包） |

### 超时与取消

| # | 自测项 | 关键答案 |
|---|---|---|
| 10 | `Promise.race` 能取消任务吗？ | **不能**。它只决定"谁先返回"，被甩在身后的任务**照跑不误**（课 8） |
| 11 | 「真取消」和「假取消」怎么观测出差别？ | 数底层的定时器：真取消后是 **0**，假取消后仍是 **1**（`demo.js` 场景 3 实测） |
| 12 | `reject` 和 `abort` 的顺序为什么不能换？ | 反过来 `race` 会先拿到 `AbortError`，上层就分不清「超时」和「主动取消」—— 而这两者在错误边界里是不同的决策（超时可重试，取消不该重试） |

### 错误与重试

| # | 自测项 | 关键答案 |
|---|---|---|
| 13 | 不可重试的错误为什么要**原样上抛**而不是包装？ | 包装会丢失原始类型与语义，上层没法判定。课 11 错误边界原则：**做不了就别接** |
| 14 | `cause` 在这里解决了什么问题？ | 重试耗尽后，外层既要知道"重试 3 次都失败了"，也要拿到**最后一次的真实错误** —— `cause` 把两者串成一条链（课 11） |
| 15 | 为什么自定义错误必须写 `this.name`？ | 不写的话 `e.stack` 首行显示成 `Error: xxx`，扫日志时第一眼就认不出来（课 11 实测） |

### 内存与缓存

| # | 自测项 | 关键答案 |
|---|---|---|
| 16 | "缓存用 Map 但不限大小"为什么算泄漏？ | 键永不释放 → 条目永不消失 → 只增不减。这就是课 12 泄漏 ④ 的标准形态 |
| 17 | 什么时候该用 `WeakMap` 代替 LRU 缓存？ | 当**键天然是对象**时（给别人的对象附加元数据）—— 自动清理、零维护。键是字符串就用不了（课 9/12） |
| 18 | 定时器为什么一定要清？ | 定时器挂着 → 回调活着 → 回调闭包引用的**所有东西**都活着，且进程退不出去（课 12 泄漏 ②） |

### this

| # | 自测项 | 关键答案 |
|---|---|---|
| 19 | `const run = queue.run` 之后调用为什么炸？ | `this` **看调用点不看出生地**。"点"没了，`this` 变 `undefined`，访问 `#defaults` 就 `TypeError`（课 5） |
| 20 | 有哪几种修复方式？ | `bind`、箭头函数属性、调用时补回"点"。本项目选**箭头函数**（在 `#makeRelease` 里） |

## 下一步

L1–L2 全绿之后，按 `--expose-gc` 跑一次内存观测会很有收获：

在 `实现/` 目录下执行（本机 Node v22.14.0 实测通过）：

```bash
cd 实现
node --expose-gc --input-type=module -e "import { ResultCache } from './src/cache.js'; const c = new ResultCache({ max: 1000 }); for (let i = 0; i < 5000; i++) c.set('k' + i, i); global.gc(); console.log('size after 5000 inserts =', c.size);"
```

实测输出：

```
size after 5000 inserts = 1000
```

**看到 `1000` 而不是 `5000`，你就亲手验证了一次「有界缓存 vs 无界 Map」的差别** —— 这正是课 12 泄漏 ④ 想让你建立的手感。

（`--input-type=module` 是让 `-e` 按 ESM 解析，否则 `import` 会报错；`--expose-gc` 只是为了让你能手动触发一次 GC，不影响结论。）
