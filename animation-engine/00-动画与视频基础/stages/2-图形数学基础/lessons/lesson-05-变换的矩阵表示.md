# 第 5 课：变换的矩阵表示

> 所属阶段：阶段 2《图形数学基础》｜ 水平：零基础
> 本课知识点：仿射变换的直觉、2D 变换矩阵、齐次坐标、绕任意点与层级变换
> 故事情节：要让线条旋转、缩放再摆到指定位置，一个一个改坐标太笨——工程师发现所有变换都能塞进一个矩阵里连乘

## 🎯 本课目标

- 说清平移为何不是线性变换，以及仿射 = 线性 + 平移
- 手写旋转 / 缩放矩阵，解释每个元素的几何含义
- 用 3×3 矩阵表达平移，举例说明变换顺序不可交换
- 把"绕点 P 旋转"拆成三步矩阵连乘，说明骨骼层级的数学本质

> ⚠️ 本课含 4 个知识点且难度集中，规划拆 **2 批**生成（首批：仿射变换的直觉、2D 变换矩阵；第二批：齐次坐标、绕任意点与层级变换）。

## 📌 知识点清单（正文待填充）

### 知识点 1：仿射变换的直觉

- 关键点：线性变换的两个条件 / 平移为什么不是线性 / 仿射 = 线性 + 平移 / 几何直觉：网格怎么变形

### 知识点 2：2D 变换矩阵

- 关键点：2×2 矩阵列的含义 / 旋转矩阵推导 / 缩放与错切 / 矩阵乘法 = 变换复合

### 知识点 3：齐次坐标

- 关键点：为什么要加一维 / 3×3 统一平移 / 变换顺序不可交换 / 列向量约定

### 知识点 4：绕任意点与层级变换

- 关键点：平移 → 旋转 → 平移回 / 父子层级的矩阵连乘 / 矩阵栈 / 骨骼变换的雏形
