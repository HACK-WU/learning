# 第 2 课：手绘工厂：关键帧、中割与律表

> 所属阶段：阶段 1《动画原理与工业流程》｜ 水平：零基础
> 本课知识点：关键帧与原画中割、律表 Exposure Sheet、分层与赛璐珞、洋葱皮与时间参考
> 故事情节：线条动起来了，但要画 24 张才够一秒——动画师发现"画得少"才是这门手艺的核心

## 🎯 本课目标

- 区分原画 / 中割 / 小原画，说明一张二张三张各自适用的动作
- 看懂并填写一份律表，说出每个栏位等价于什么数据字段
- 解释分层如何减少重绘，以及它与"伪 3D"的关系
- 说明洋葱皮解决什么问题，以及它在数字工具里的等价实现

> ⚠️ 本课含 4 个知识点，规划拆 **2 批**生成（首批：关键帧与原画中割、律表；第二批：分层与赛璐珞、洋葱皮与时间参考）。

## 📌 知识点清单（正文待填充）

### 知识点 1：关键帧与原画中割

- 关键点：原画 key / 中间帧 inbetween / 小原画 / 一张二张三张的取舍

### 知识点 2：律表 Exposure Sheet

- 关键点：律表结构 / 帧号行与图层列 / 摄影指示与口型 / 律表就是"手写的动画数据结构"

### 知识点 3：分层与赛璐珞

- 关键点：cel 片 / 背景与前景分离 / 复用与不重复绘制 / 分层是伪 3D 的起点

### 知识点 4：洋葱皮与时间参考

- 关键点：onion skin / 前后帧半透明叠加 / 与律表如何配合 / 数字工具中的等价实现
