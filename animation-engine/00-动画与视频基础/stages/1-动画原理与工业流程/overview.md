# 阶段 1：动画原理与工业流程

> 所属课程：2D 动画与视频基础 ｜ 故事章节：**线条第一次动起来**
> 上一阶段：无（起点） ｜ 下一阶段：[阶段 2：图形数学基础](../2-图形数学基础/overview.md)

## 🎯 本阶段目标

- 说清"动画"在生理层面（人眼为什么会被骗）、物理层面（时间如何被离散成帧）、工程层面（工业流水线怎么组织）分别是什么。
- 能看懂并手写一个律表（X-sheet），知道每一列在表达什么数据。
- 能指出迪士尼十二原则中哪些可以被算法化、哪些必须留给人工审美——这直接决定了你要写的引擎能自动化到什么程度。

## 📍 学习重点

- **动画成立的前提是人的视觉特性**：24 fps 够用不是技术凑整，是人的视觉系统有它的临界值。不理解这点，后面所有参数调优都是拍脑袋。
- **帧与时间解耦**：帧号只是索引，时间是另一条轴。这个分离正是需求文档里 `frame` 字段能成立的前提。
- **关键帧 + 中割 + 分层是"降本三件套"**：传统工业不是靠画得多，是靠画得少。需求文档的"分层矩阵"就是这个思路的数据化版本。
- **十二原则是"动作好看"的经验编码**：其中"慢入慢出"对应缓动函数、"弧线运动"对应插值路径——阶段 2 会给出它们的数学形式。

## ✅ 必须掌握的知识点

| 知识点 | 所属课 | 学完应能 |
|--------|--------|----------|
| 视觉暂留与似动现象 | 课 1 | 说清动画成立依赖的是哪种视觉特性，以及常见说法的错处 |
| 帧与帧率 | 课 1 | 给定时长与 fps 算出总帧数；解释一拍二与一拍三的取舍 |
| 时间轴与播放模型 | 课 1 | 解释帧号与时间的换算，说明需求文档 `frame` 字段的作用 |
| 关键帧与原画中割 | 课 2 | 区分原画 / 中割 / 小原画；说明一张二张三张各适用于什么动作 |
| 律表 Exposure Sheet | 课 2 | 看懂并填写一份律表，说出每个栏位等价于什么数据字段 |
| 分层与赛璐珞 | 课 2 | 解释分层如何减少重绘，以及它与"伪 3D"的关系 |
| 洋葱皮与时间参考 | 课 2 | 说明洋葱皮解决什么问题，以及它在数字工具里的等价实现 |
| 时间与间距 | 课 3 | 用"间距"解释速度感；画出匀速与缓入缓出的间距对比 |
| 挤压拉伸·预备·跟随与重叠 | 课 3 | 各举一例说明四条原则，并指出引擎如何实现其中之一 |
| 十二原则中哪些能变成算法 | 课 3 | 划清"可自动化"与"需人工审美"的边界，给出判断依据 |
