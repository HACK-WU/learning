# 第 7 课：光栅与矢量

> 所属阶段：阶段 3《渲染与合成基础》｜ 水平：零基础
> 本课知识点：光栅图像、矢量图形、两种表示在引擎中的分工
> 故事情节：线条的数学状态算好了，可显示器只认像素——工程师必须在"便于计算"和"便于显示"两种表示之间做出分工

## 🎯 本课目标

- 用 NumPy 表示一个 RGBA 画布，解释锯齿产生的根本原因
- 说清路径 / 控制点 / 描边与填充，解释"分辨率无关"意味着什么
- 说明引擎中何阶段用矢量、何阶段必须光栅化，以及抗锯齿处于哪一步

## 📌 知识点清单（正文待填充）

### 知识点 1：光栅图像

- 关键点：像素网格 / 分辨率 / 通道与位深 / 锯齿与光栅化的本质

### 知识点 2：矢量图形

- 关键点：路径与控制点 / 分辨率无关 / 描边与填充 / 数据即图形

### 知识点 3：两种表示在引擎中的分工

- 关键点：矢量存储 + 光栅呈现 / 抗锯齿 / 与需求文档节点矩阵的对应 / 何时必须光栅化
