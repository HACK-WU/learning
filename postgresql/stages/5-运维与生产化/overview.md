# 阶段 5 · 运维与生产化

> 故事章节：「不只是能用，还要撑得住」——硬盘坏了、生产宕机、主从延迟 8 小时，故事进入最终章

## 阶段目标

本阶段结束时，你能：

1. **备份恢复**：能选对方式（逻辑 vs 物理 vs PITR）并验证恢复成功
2. **主从高可用**：能搭一套可工作的主从流复制 + 知道何时该上 Patroni
3. **监控与性能**：能搭出关键指标的监控 + 用 `pg_stat_*` 视图查问题
4. **扩展与安全**：常用扩展会用、用户权限会配、连接池会调、迁移路径有概念

## 学习重点

1. **备份恢复**：漏一个备份就是"职业生涯的终点"，必须真做一次恢复演练
2. **复制原理**：WAL 在主备之间怎么发，怎么保证不丢数据
3. **监控落地**：连接数 / TPS / QPS / 缓存命中 / 复制延迟 五大核心指标
4. **生产化实战**：权限隔离、连接池、扩展、迁移

## 本阶段在故事主线中的章节定位

这是故事的「**收**」——主角终于不再是单机里的一个脆弱数据点，而是分布在主备集群中、被备份托底、被监控保护、被安全壁垒隔离的"全套生产化资产"。读者从此进入"生产 PG 工程师"的世界。

## 阶段内闭环

保住数据 → 高可用 → 看清楚 → 上生产化。**学完课 17 后，你应该能搭出一个"主库 + 备库 + 监控 + 备份"四件套的本地生产化沙箱**。

## 学习节奏

- 本阶段 12 知识点，建议 **5–7 天** 完成
- **实操 ≥ 40%**：每章至少做一次端到端的实操演练（如：备份+恢复 / 主从搭建 / 监控配置）

## 阶段产出物

学完本阶段后，你应有：

- 一套跑起来的主从复制（一个 primary + 一或多个 standby）
- 一份"备份策略 + 恢复演练报告"
- 一份"监控告警规则清单"
- 一份权限矩阵（哪些角色能做哪些事）
