# Consul 场景解法库

> **怎么用**：每个场景先自己想"怎么做"，再点进场景文件看解法。**先想后看，能力才长出来**。
> 配套：[08-实战经验.md](../08-实战经验.md)（为什么）｜ [09-排障速查手册.md](../09-排障速查手册.md)（出错了怎么办）。
> **解法来源**：本课程实测（标注课 N，本机 Consul 2.0.2 / Windows）+ 官方文档 + 领域公认实践；无来源的推测不进「解法一览」。
> **读图方式**：每个解法都配一张**机制图**（入 `assets/`）——画清该解法的核心逻辑，**并在图上用红框标出它的失效点 / 代价**。看解法时先读图，再读代码：图告诉你"谁挡在哪、会在哪炸"，代码告诉你"怎么写"。
> **版本口径**：命令行与 API 行为以 **Consul 2.0.2** 为准（本机实测环境），机制层结论跨 1.x / 2.x 通用；凡涉及版本差异处已在对应解法内标注。

> **结课寄语**：这些场景没有"标准答案"——每个解法的价值在于**代价换什么**。你在课程里学到的能力（服务发现 / KV 与阻塞查询 / 会话锁 / Connect / ACL / 读模式 / 选型框架）就是这些解法手里的牌；什么时候出哪张，靠的是场景里练出来的判断。
