# 课 3：五分钟跑起来看一眼（轻量体验课）

> ⏳ 本课为骨架，正文将在 Phase 2 展开填充。
> 📌 定位说明（大纲评审约定）：本课为可选体验课，决策参考型学习者可跳过直接进入阶段 2；但"眼见为实"对建立直觉有实际帮助，推荐快速过一遍。

## 本课目标

用最小代价把 Consul 跑起来，亲手完成"注册 → 查询 → 健康检查"闭环，把阶段 1 的概念落到看得见的界面上。

## 情节定位

小林不听PPT吹牛，要求现场演示：五分钟，让一个服务在 Consul 里"活"起来。

## 知识点清单

### 知识点 1：dev 模式启动与 UI

- 关键点：`consul agent -dev` 一条命令的边界（仅开发体验，不可生产）
- 关键点：Web UI（默认 8500 端口）与 `consul members`
- 关键点：安装方式概览（二进制 / 包管理器，官方渠道）

### 知识点 2：注册与查询服务

- 关键点：配置文件注册服务（service 定义 + address/port/tags）
- 关键点：HTTP API 查询（`/v1/catalog/service/...` 与 `/v1/health/service/...`）
- 关键点：DNS 接口查询（`dig @127.0.0.1 -p 8600 web.service.consul`）

### 知识点 3：健康检查与状态流转

- 关键点：给服务挂一个 HTTP 健康检查
- 关键点：passing → critical 的状态流转与查询结果变化
- 关键点：从 UI 观察剔除效果，回扣"注册中心四大职责"
