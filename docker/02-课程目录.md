## 🔧 命令速查索引

> **怎么用**：知道要干什么、忘了命令怎么写 → 从这里找命令；想查某个命令的坑 → 点进对应那一课。
> **读法**：「在哪一课」列指向该命令**被系统讲解**的课。标注 `（速查卡）` 的命令不单独展开成知识点，只在该课末尾的「📋 命令速查卡」里给出语法与注意事项。
> **版本基线**：Docker Engine **29.x**（核查于 2026-09）。Compose 一律用 **V2** 写法 `docker compose`（无连字符）。

### 2. 镜像：拉取 · 构建 · 分发

| 命令 | 一句话用途 | 在哪一课 |
|------|-----------|---------|
| `docker pull <镜像>` | 只拉取镜像不运行 | [课 1](stages/1-容器与镜像基础/lessons/lesson-01-为什么需要Docker.md) |
| `docker pull <镜像>@sha256:<digest>` | **按摘要拉取**——内容与版本都锁死，谁拉都一样 | [课 3](stages/1-容器与镜像基础/lessons/lesson-03-镜像的里子：分层与仓库.md) |
| `docker images` | 列本地镜像（REPOSITORY / TAG / IMAGE ID / SIZE） | [课 1](stages/1-容器与镜像基础/lessons/lesson-01-为什么需要Docker.md) |
| `docker image ls -f dangling=true` | 只看虚悬镜像（`<none>:<none>`）——清理前先看清单 | [课 3](stages/1-容器与镜像基础/lessons/lesson-03-镜像的里子：分层与仓库.md) |
| `docker build -t <名:标签> .` | 按 Dockerfile 构建镜像——**末尾那个 `.` 是构建上下文，不是 Dockerfile 的路径** | [课 4](stages/2-镜像工程/lessons/lesson-04-Dockerfile入门.md) |
| `docker build -f <路径> .` | Dockerfile 不叫 `Dockerfile` 或不在当前目录时用 | [课 4](stages/2-镜像工程/lessons/lesson-04-Dockerfile入门.md) |
| `docker build --build-arg K=V .` | 给 Dockerfile 里的 `ARG` 传值 | [课 4](stages/2-镜像工程/lessons/lesson-04-Dockerfile入门.md) |
| `docker build --target <阶段名> .` | 只构建到多阶段的某一阶段——**调试构建失败的利器** | [课 4](stages/2-镜像工程/lessons/lesson-04-Dockerfile入门.md) / [课 6](stages/2-镜像工程/lessons/lesson-06-多阶段构建与镜像瘦身.md) |
| `docker build --no-cache .` | 忽略全部缓存从头构建（**RUN 缓存不会自动过期**，要强制刷新就用它） | [课 4](stages/2-镜像工程/lessons/lesson-04-Dockerfile入门.md) |
| `docker build --secret id=<id>,src=<文件> .` | 配合 `RUN --mount=type=secret` 传**构建期**密钥（**不进镜像也不进构建缓存**；不支持时改用 `docker buildx build`） | [课 5](stages/2-镜像工程/lessons/lesson-05-启动命令与配置注入.md) |
| `docker images --format 'table {{.Repository}}\t{{.Tag}}\t{{.Size}}'` | 自定义列输出，用来**对比候选基础镜像的体积** | [课 6](stages/2-镜像工程/lessons/lesson-06-多阶段构建与镜像瘦身.md) |
| `docker history <镜像>` | 逐层看构建历史与各层体积——**`0B` 的行 = 只改元数据，不产生层** | [课 3](stages/1-容器与镜像基础/lessons/lesson-03-镜像的里子：分层与仓库.md) / [课 6](stages/2-镜像工程/lessons/lesson-06-多阶段构建与镜像瘦身.md) |
| `docker image inspect <镜像>` | 看镜像元数据：分层、环境变量、CMD、架构 | [课 3](stages/1-容器与镜像基础/lessons/lesson-03-镜像的里子：分层与仓库.md) |
| `docker tag <源> <目标>` | 给已有镜像加新标签——**push 之前必做** | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `docker push <镜像>` | 推到远端仓库 | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `docker inspect <镜像> --format '{{index .RepoDigests 0}}'` | 看 **digest** —— 真正不可变的标识（tag 可被覆盖） | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `docker login -u <用户> --password-stdin` | 非交互登录（官方：避免密码进 shell history 与日志） | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `--cache-to type=<后端>,ref=<位置>,mode=max` | **导出**构建缓存（`inline`/`registry`/`local`/`gha`） | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `--cache-from type=<后端>,ref=<位置>` | **导入**构建缓存（可重复指定多个源） | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `docker buildx create --driver docker-container --bootstrap --use` | 默认驱动未启用 containerd 时，用它才能用外部缓存后端 | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) |
| `docker rmi <镜像>` | 删镜像；被容器占用时删不掉，得先删容器 | [课 3](stages/1-容器与镜像基础/lessons/lesson-03-镜像的里子：分层与仓库.md) `（速查卡）` |
| `docker save` / `docker load` | 导出 / 导入镜像 tar 包（离线环境迁移） | [课 13](stages/4-生产落地/lessons/lesson-13-CI-CD与交付流水线.md) `（速查卡）` |

| `docker events` | 看守护进程事件流（排障利器） | [课 11](stages/4-生产落地/lessons/lesson-11-日志与可观测性.md) |

### 4. `docker run` 常用参数 🔥

> 这一组是 Docker 的"动词变位表"，单独列出来——它们散落在课 2 / 5 / 7 / 8 / 10 / 12，课 2 会给一张参数地图串起来。

| 参数 | 一句话用途 | 在哪一课 |
|------|-----------|---------|
| `-d` | 后台运行（detached） | [课 2](stages/1-容器与镜像基础/lessons/lesson-02-跑起来第一个容器.md) |
| `-it` | 分配交互式终端（`-i` 保持 stdin、`-t` 分配 tty，通常连用） | [课 2](stages/1-容器与镜像基础/lessons/lesson-02-跑起来第一个容器.md) |
| `--name <名字>` | 给容器起名，后续命令用名字代替 ID | [课 2](stages/1-容器与镜像基础/lessons/lesson-02-跑起来第一个容器.md) |
| `--rm` | 停止后自动删除——**跑一次性任务务必加** | [课 2](stages/1-容器与镜像基础/lessons/lesson-02-跑起来第一个容器.md) |
| `-p <宿主端口>:<容器端口>` | 发布端口（⚠️ **默认绑 0.0.0.0，不是只有本机**；限本机写 `127.0.0.1:宿主:容器`） | [课 8](stages/3-数据与网络/lessons/lesson-08-容器网络.md) |
| `-P` | 自动发布镜像里**所有 `EXPOSE` 过**的端口到**随机高位端口** | [课 8](stages/3-数据与网络/lessons/lesson-08-容器网络.md) |
| `docker port <容器>` | 查看容器**实际发布**的端口映射 | [课 8](stages/3-数据与网络/lessons/lesson-08-容器网络.md) |
| `-v 卷或路径:容器路径` | 挂载卷或目录（简写；**源路径不存在时会自动建目录**） | [课 7](stages/3-数据与网络/lessons/lesson-07-数据持久化.md) |
| `--mount type=volume,src=<卷>,dst=<路径>` | 挂具名卷（**官方推荐**；省略 `src` 即为匿名卷） | [课 7](stages/3-数据与网络/lessons/lesson-07-数据持久化.md) |

| `--mount type=tmpfs,dst=<路径>` | 内存挂载（简写 `--tmpfs <路径>`；仅 Linux，容器停即消失） | [课 7](stages/3-数据与网络/lessons/lesson-07-数据持久化.md) |
