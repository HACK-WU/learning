# 应用实战索引

> 用法：学完一课，来这里找对应的动手篇——**跟着作者走一遍"从幼稚到像样"的演进**，把知识点焊进真实用法。
> 与 `02-课程目录.md` 同节奏更新；**不配实战的课不列入**（按需配套是常态，不是缺漏）。

## 怎么判定的（应用实战三问）

每课是否配实战，按三问决定，**三问都过才配**：

1. **场景可得性**：本课知识点能否自然映射到"一个现实任务"（一句话说清"拿它做什么"）？
2. **演进空间**：能否凑出"基础实现 → 它的问题 → 综合实现"至少两跳（本课知识点可组合）？
3. **非硬凑**：场景不需大量引入本课之外的知识即可成立？

按此口径，本课程序列为**不配**的课：课 1（纯概念铺垫）、课 2（环境准备课，规范明确豁免）、持久化 / 主从哨兵 / 集群（偏原理与运维搭建，强配会硬凑）、课 9（诊断与选型决策，非"做一个东西"）。
