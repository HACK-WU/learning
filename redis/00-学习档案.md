### 本机环境约束（备课实测，2026-08-31）

| 项 | 值 |
|----|-----|
| WSL | Ubuntu 24.04.4 LTS（noble），Windows 侧无 Docker、无 Redis |
| 系统自带 Redis | 7.0.15（apt 源最高即此版本，7.0 线已 EOL） |
| 官方源连通性 | `packages.redis.io` 与 `download.redis.io` 均 HTTP 200 |
| 编译工具链 | gcc 13.3.0、GNU Make 4.3 可用 |

> 命令执行方式：PowerShell 下用 `$env:WSLENV=""; & "C:\Windows\System32\bash.exe" -c "..."` 调用 WSL，Windows 盘挂载在 `/mnt/d` 下。
