## 每篇的统一结构

1. **场景描述** —— 具体的、带数字的场景（配一张全场景结构图，8 篇各一张 SVG）
2. **🔒 先自己想 30 秒** —— **常显**，不要急着看答案
3. **💡 提示**（折叠）—— 卡住了再看，分维度提示
4. **📖 展开解法**（折叠）—— 解法一览（≥3 种，含**按题定制的效果对比列**与各解法的代价）→ 每个解法独立展开（机制图 + 读图指引 / 思路 / 代码 / 代价 / 边界 / 课程挂钩 / 来源）→ 推荐路径（递进，不是一次全上）→ **非 Redis 替代路线**（表格对比）→ 做错会踩的坑

> 折叠方向是刻意设计的：**问题常显、答案折叠**。如果一进来就能看到解法一览，"先想后看"就失效了。
