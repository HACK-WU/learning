# 阶段 1 · 环境与选型

> 一句话：**先把环境立住、把选型判据讲透，再谈怎么写代码**。

## 本阶段要解决的冲突

你照着文档 `pip install` 了一个库，写了 producer/consumer，跑通了。然后你看到别人用另一个库，API 长得不一样，网上说"这个快 7 倍"，还有人说"那个停更了别用"——**你不知道自己选得对不对，甚至不知道该问什么问题**。

本阶段不急着写代码，先解决三件事：环境怎么立、三个库怎么选、以及**换库时哪些 API 会静默崩掉**。
