# 阶段 2 · 理解层：用 kafka-python 读协议

> 一句话：**不读源码，你只能抄配置；读了源码，你才知道为什么这么配**。

## 本阶段要解决的冲突

你会用 `producer.send()` 和 `for msg in consumer`，但被问到"`send()` 返回了，消息到底到 Broker 了吗"，你答不上来——因为你不知道这两个调用背后发生了什么。

本阶段用 `kafka-python` 读源码。选它不为快，为**它是纯 Python，唯一能读**。confluent-kafka 是 C 扩展，这一层用不了。
