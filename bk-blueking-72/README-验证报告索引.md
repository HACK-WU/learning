## 快速复盘

**问题**：单机全量启动蓝鲸 → 组件抢资源变慢 → 激进探针误杀 → 连锁 CrashLoop

**解法**：分批启动 + 验证完即裁

**关键认知**：
1. 唯一标记法验证数据链路（不只看 Pod Ready）
2. 副本为 0 ≠ 链路不通（filebeat 直连 ES）
3. 401/302/业务异常都可能是健康信号
4. ERROR 计数 ≠ 故障（看时间和内容）
5. DB 级验证比日志硬
6. 起组件前先查探针
7. 凭据不要靠猜，列 keys
