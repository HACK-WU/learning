## 四、为什么必须配 hosts

ingress 完全靠域名分发，**直接访问 IP 一律 404**：

```text
http://localhost/               -> 404
http://172.26.238.136/          -> 404
http://bkpaas.paas.example.com/  -> 200  ✅
```

`paas.example.com` 是 chart 默认虚构域名，公网不存在。

**不能只配主入口** —— 前端页面写死依赖：

```javascript
var LOGIN_SERVICE_URL   = 'http://paas.example.com/login'
var BK_APIGW_URL        = 'http://apigw.paas.example.com'
var BK_COMPONENT_API_URL = 'http://bkapi.paas.example.com'
```

只配 `bkpaas.paas.example.com` 的话，页面能开但**登录会失败**。

## 五、WSL IP 变了怎么办

WSL 重启后 IP 会变，届时所有域名失效。

**一键修复**（脚本自动探测新 IP 并覆盖旧条目）：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\projects\learning\bk-blueking-72\assets\setup-hosts.ps1"
```

**手动修复**：查新 IP → 编辑 hosts → 替换旧的 IP 段

```powershell
wsl.exe hostname -I
notepad C:\Windows\System32\drivers\etc\hosts
```

## 六、hosts 写入的坑（重要）

改 hosts 可能**清空原文件**，处理顺序不能错：

1. **先备份**（脚本自动做，命名 `hosts.bak.时间戳`）
2. **验证备份可用**（本次备份 1209 字节）
3. **报错后先看当前状态，不要直接重试**

`Set-Content` 会出现"**删了旧的、没写新的**"（文件变 0 字节但报错），此时重试会在空文件上追加，**原条目全丢**。

可靠写法是用 .NET `FileStream` 独占模式一次性写入（见 [setup-hosts.ps1](assets/setup-hosts.ps1)）。

> 注释用英文，中文经 ASCII 编码会变乱码。

### 9.3 装完后还需加桌面图标（官方步骤）

```bash
cd /root/bk72/install/blueking/
scripts/add_user_desktop_app.sh -u "admin" -a "bk_monitorv3"
scripts/set_desktop_default_app.sh -a "bk_monitorv3"
```

**根因已最终锁定**（2026-09-23 第三轮，闭环验证）：
**ESB 签名密钥 ≠ GSE 校验密钥**，所以 `invalid signature`。

| 对象 | 公钥 md5 |
|---|---|
| ESB 签发用 | `0e82d670218b3380bcbc15d87625a81e` |
| `bk-esb` / `apigw` gateway | `0e82d670...`（与 ESB 一致） |
| `bk-gse` gateway = GSE 证书 | `0e18be8a0f385db7ba21c81b58fcc265`（**与 ESB 不同**） |

根子在 `SYNC_ESB_JWT_KEY_GATEWAY_NAMES` 只含 `bk-esb` 和 `apigw`，**不含 `bk-gse`**，
导致 bk-gse 的密钥没被同步成 ESB 那把。

**修复方案**（均需改集群状态，待用户授权）：
A. 把 `bk-gse` 加入该设置后重跑 `sync_esb_jwt_key_to_gateway`（推荐，官方机制）；
B. 换 ESB 密钥为 bk-gse 那对；C. 给 GSE 换证书。
详见手册 6.12。**当前未执行任何修复。**
